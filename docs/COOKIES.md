# Как получить cookies из браузера и подключить их в Video Downloader

Cookies позволяют передать yt-dlp браузерную сессию: например, вход в аккаунт или уже выполненное подтверждение возраста. Приложение принимает **путь к текстовому файлу cookies в формате Mozilla/Netscape**. Открытая вкладка браузера сама по себе не передаёт сессию загрузчику; автоматического чтения профиля браузера из интерфейса пока нет.

## 1. Подготовить браузерную сессию

1. Открой нужный сайт в браузере и в нужном профиле пользователя.
2. Войди в свой аккаунт, если материал требует авторизации. Если сайт показывает проверку возраста или CAPTCHA, пройди её обычным способом.
3. Открой конкретное видео и проверь, что оно действительно воспроизводится. Экспорт cookies не даст доступ к материалу, который этому аккаунту недоступен.

## 2. Экспортировать файл из Chrome или Edge

В [официальной FAQ yt-dlp](https://github.com/yt-dlp/yt-dlp/wiki/FAQ#how-do-i-pass-cookies-to-yt-dlp) для Chrome приведено расширение **Get cookies.txt LOCALLY**:

[Открыть Get cookies.txt LOCALLY в Chrome Web Store](https://chrome.google.com/webstore/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc).

1. Установи расширение из указанного магазина. В Edge может потребоваться разрешить установку расширений из других магазинов.
2. Вернись на открытую страницу нужного сайта, где уже выполнен вход.
3. Открой меню расширения. Выбери экспорт cookies текущего сайта, а не всех сайтов браузера; название команды может отличаться между версиями расширения.
4. Сохрани файл в формате **Netscape / cookies.txt**. Например: `C:\Users\<имя>\Documents\VideoDownloader\cookies-youtube.txt`. Создай папку, если её ещё нет.

Проверяй название: требуется вариант **LOCALLY** по ссылке из FAQ yt-dlp. Не устанавливай похожее по имени расширение вместо него.

## 3. Экспортировать файл из Firefox

В FAQ yt-dlp приведено расширение **cookies.txt**:

[Открыть cookies.txt в Mozilla Add-ons](https://addons.mozilla.org/en-US/firefox/addon/cookies-txt/).

1. Установи расширение из Mozilla Add-ons.
2. Открой сайт в том профиле Firefox, где выполнен вход, и проверь доступ к видео.
3. В меню расширения выбери экспорт cookies текущего сайта.
4. Сохрани файл `.txt` в формате Netscape в постоянную папку, например `Documents\VideoDownloader\cookies-firefox.txt`.

## 4. Подключить файл в приложении

1. В основном окне найди поле **Cookies** в правой панели **Preview** с настройками.
2. Нажми **…** справа от поля и выбери экспортированный `.txt` либо вставь в поле полный путь к нему. Вставлять содержимое файла или строку HTTP-заголовка `Cookie:` не нужно.
3. Для подписки установи путь **до** нажатия **«Проверить»** / **«Добавить и проверить»**. Если проверка уже завершилась ошибкой, повтори её после выбора файла.
4. Для обычной загрузки укажи файл до **Start**, затем добавь URL и запусти скачивание. Если URL уже добавлен, для повторного запроса неудавшихся метаданных выбери его в очереди ещё раз.
5. Если файл больше не нужен, очисти поле **Cookies**.

Приложение сохраняет путь в настройках и читает файл по этому пути при следующих запросах yt-dlp. Оно не копирует файл в собственное хранилище, поэтому не удаляй и не перемещай его после выбора. Для другого сайта можно экспортировать отдельный файл и менять путь перед проверкой или запуском загрузок. Уже запущенный процесс не получает изменения пути задним числом.

Cookies передаются yt-dlp при получении метаданных, полном обходе подписок и скачивании. Необязательная RSS/Atom-лента читается отдельным HTTP-клиентом и этот файл cookies не использует. Загрузка самих изображений обложек также не импортирует браузерный cookie jar: доступность метаданных не гарантирует доступ к каждому изображению.

## Как проверить формат

Открой файл локально в текстовом редакторе. Первая строка должна быть одной из следующих:

```text
# Netscape HTTP Cookie File
```

или:

```text
# HTTP Cookie File
```

Ниже идут записи, разделённые табуляцией. JSON из DevTools, скриншот, копия заголовка `Cookie:` и простое переименование другого формата в `.txt` не подходят. Лучше повторить правильный экспорт, чем собирать файл вручную.

## Если не сработало

| Симптом | Что сделать |
| --- | --- |
| После выбора файла сайт всё ещё требует вход | Проверь, что экспорт выполнен из нужного профиля браузера после входа и для нужного сайта. Экспортируй заново. |
| yt-dlp не распознаёт файл cookies | Проверь формат Netscape и первую строку. Повтори экспорт в `.txt`; не используй JSON. |
| Ссылка работала раньше, а теперь даёт 401/403 или проверку пользователя | Открой видео в браузере, обнови вход/подтверждение и экспортируй новый файл. При необходимости нажми **Update yt-dlp**. Cookies не гарантируют обход всех ограничений сайта. |
| Подписка не видит выбранный файл | Укажи путь в основном окне до новой проверки. Проверь, что файл существует по этому пути и доступен для чтения. |
| Название есть, но обложка осталась прежней или отсутствует | Превью кешируется до 72 часов. Для полного повторного получения закрой приложение и удали только папку `preview-cache` в каталоге настроек, затем снова выбери URL. Это не удаляет скачанные видео, подписки и историю. |
| RSS требует собственную авторизацию | Cookies из этого поля не передаются RSS-клиенту. Проверь, доступна ли лента без входа. |

Файл cookies может давать доступ к твоему аккаунту. Не отправляй его в чат, issue или репозиторий, не включай в архив с логами. Храни локально; если файл попал к посторонним, заверши соответствующие сессии в настройках сайта и выполни вход заново.
