# Скачивание видео: четыре пользовательских сценария

Это руководство для Windows-приложения `VideoDownloader.exe`. Подробное описание полей и кнопок находится в [справочнике интерфейса](../GUI.md), а взаимодействие компонентов — в [схемах работы](ARCHITECTURE.md).

- [Одно видео YouTube](#youtube-video).
- [Плейлист YouTube по отдельным роликам](#youtube-playlist).
- [Новые материалы из подписки](#subscriptions).
- [Подписка с RSS / Atom](#rss).

## Перед началом

1. Скачай Windows ZIP из [последнего релиза](https://github.com/bespalovnikita/video-downloader/releases/latest), распакуй его целиком и запусти `VideoDownloader.exe`. Соседние файлы и папки нужны приложению; переносить один EXE отдельно не следует. PowerShell, Python и установленный .NET Runtime для запуска не требуются.
2. В разделе **Dependencies** проверь зависимости. Если FFmpeg или ffprobe отсутствуют, нажми **Install FFmpeg** и дождись завершения установки. Перед скачиванием приложение проверяет оба инструмента.
3. Выбери **Profile**: например, **«Универсальный»** или **«Совместимый MP4»**. Затем при необходимости измени качество, субтитры и **Archive by date**. Выбор другого профиля заново задаёт связанные настройки, включая архивирование по дате.
4. В **Output folder** укажи папку, например `D:\Video`. Это пример: можно выбрать другой доступный каталог кнопкой **…**.
5. Если источник требует авторизации, укажи в **Cookies** путь к экспортированному файлу cookies в формате Netscape: [отдельная инструкция для Chrome / Edge / Firefox](COOKIES.md). Открытая вкладка браузера сама по себе не передаёт вход приложению.

Добавление ссылки, получение названия и проверка подписки не являются скачиванием. Обычная очередь запускается кнопкой **▶ Start**. Исключение — обычные ссылки, добавленные вручную во время работающей загрузки: они могут присоединиться к текущей сессии. Материалы подписок всегда ждут следующего **Start**.

В примерах ниже `VIDEO_ID`, `PLAYLIST_ID`, `CHANNEL` и `CHANNEL_ID` — обозначения, которые нужно заменить своими значениями. Надёжнее копировать настоящий адрес из браузера.

<a id="youtube-video"></a>

## 1. Скачать одно видео с YouTube

Пример формы адреса:

```text
https://www.youtube.com/watch?v=VIDEO_ID
```

1. Скопируй ссылку на нужный ролик. Если нужен только он, используй адрес без параметра `list`: ссылка на видео, открытое внутри плейлиста, может передать yt-dlp весь плейлист.
2. Вставь URL в поле над **Queue** и нажми **+ Add**. Для ссылки в буфере можно использовать **Paste**.
3. Дождись фонового получения метаданных. Чтобы видеть названия в таблицах, включи **«Показывать названия видео вместо URL»**. Для запуска скачивания ждать обложку необязательно.
4. Проверь **Profile** и **Output folder**, затем нажми **▶ Start**.
5. Если приложение обнаружит эту точную ссылку в истории, выбери повторное скачивание или пропуск. Отмена диалога не запускает загрузку.
6. Дождись успешного завершения. Выбери результат в **Downloads** и нажми **Open file** или **Show in folder**. Кнопка **«📂 Открыть папку загрузок»** открывает настроенный каталог без выбора строки.

**Результат:** файл появится в `D:\Video`, а при включённом **Archive by date** — в `D:\Video\ГГГГ-ММ-ДД`. Имя по умолчанию строится по шаблону `%(title)s [%(id)s].%(ext)s`; расширение зависит от настроек и доступных форматов. Ошибка обложки не отменяет известное название видео.

**Pause / Resume** приостанавливает и продолжает сессию, **Stop** отменяет её с очисткой временных файлов. Кнопка **↻ Failed** повторяет неудачные задания. **Remove** для начатого или завершённого задания может удалить его файлы после подтверждения — это не просто скрытие строки.

<a id="youtube-playlist"></a>

## 2. Скачать видео из плейлиста YouTube

Если нужен один ролик из плейлиста, открой его на YouTube, скопируй ссылку без параметра `list` и следуй [первому сценарию](#youtube-video). Ниже описан импорт всего доступного набора с отдельной задачей на каждый ролик.

Для отдельных строк, статусов и повторов каждого ролика используй импорт через **«Подписки»**. Источник можно оставить для будущих ручных проверок или удалить после разового импорта.

Пример формы адреса:

```text
https://www.youtube.com/playlist?list=PLAYLIST_ID
```

1. В основном окне настрой профиль и **Output folder**.
2. Нажми **«Подписки»**. В поле **«Канал или плейлист — любой сайт, поддерживаемый yt-dlp»** вставь URL плейлиста.
3. В **«Краткое имя / папка (необязательно)»** введи, например, `Обучение`. Если оставить поле пустым, после успешной проверки программа возьмёт название канала/автора, а при его отсутствии — название коллекции.
4. Включи **«Добавить все существующие материалы в очередь (без скачивания)»**. Для скачивания текущего плейлиста этот выбор важен: без него существующие ролики станут только исходным набором.
5. Нажми **«Добавить и проверить»**. Первая полная проверка начнётся сразу; не нужно дополнительно нажимать **«Проверить»** во время её выполнения.
6. Дождись успешного результата. В карточке проверки видны текущий источник, этап и время; затем проверь число материалов, принятых в обычную очередь. Уже обработанные URL могут не добавиться повторно.
7. Вернись в основное окно и нажми **▶ Start**. Каждый принятый ролик получит отдельное задание.

**Результат:** при указанном имени `Обучение` файлы будут сохраняться в `D:\Video\Обучение`, а с архивированием — в `D:\Video\ГГГГ-ММ-ДД\Обучение`. Ошибку конкретного видео можно повторить отдельно. Переименование подписки позже влияет на новые добавления, а имя папки уже принятых заданий сохраняется.

Удаление подписки кнопкой **«Удалить подписку»** не удаляет уже добавленную обычную очередь, скачанные файлы и историю.

### Если добавить URL плейлиста обычной кнопкой + Add

Такой URL остаётся **одним заданием**, переданным yt-dlp. Он не разворачивается приложением в отдельные строки роликов: yt-dlp может скачать коллекцию, превью относится к первому материалу при наличии его метаданных, а общие название и прогресс меняются по ходу работы. История учитывает исходный URL плейлиста, не каждый URL его видео; **Open file** работает с одним из итоговых файлов.

Для контроля каждого ролика и согласованного учёта в подписках используй описанный выше импорт. Прямое скачивание плейлиста не доказывает подпискам, что каждый его ролик уже был скачан отдельно.

<a id="subscriptions"></a>

## 3. Скачивать новые материалы по подписке

Подписка сохраняет канал или плейлист и помнит уже обнаруженные URL. Проверки запускаются вручную; программа не проверяет источники по расписанию и не начинает скачивание автоматически.

Пример формы адреса раздела обычных видео YouTube-канала:

```text
https://www.youtube.com/@CHANNEL/videos
```

Выбранный URL определяет проверяемую коллекцию. Адрес вкладки обычных видео не означает подписку одновременно на все остальные разделы канала.

### Первая проверка

1. Открой **«Подписки»**, укажи URL источника и при необходимости краткое имя, например `Канал 123`.
2. Выбери, что делать с уже существующими видео:

   | Флаг «Добавить все существующие материалы…» | Что произойдёт после первой успешной проверки |
   | --- | --- |
   | Выключен | Текущий набор запоминается как исходный; старые видео не ставятся в очередь и не предлагаются как новые. Ранее успешно обработанные URL могут отображаться в результатах как обработанные. |
   | Включён | Ещё не обработанные существующие видео принимаются в обычную очередь и ждут Start. Известные успешные URL сразу отмечаются обработанными. |

3. Нажми **«Добавить и проверить»** и дождись полного успешного обхода. Неудачная первая проверка не устанавливает исходный набор; после исправления причины её можно повторить кнопкой **«Проверить»**.
4. Если выбран импорт существующих видео, запусти их **▶ Start** в основном окне.

### Следующие проверки

1. Когда нужно найти новинки, выбери подписку и нажми **«Проверить»**. **«Проверить все»** проверяет все неприостановленные подписки.
2. Дождись завершения. Новым считается точный URL, которого программа раньше не встречала в этой подписке; дата публикации сама по себе не определяет новизну.
3. В **«Входящие и результаты»** выдели нужные материалы и нажми **«В очередь; запуск кнопкой Start»**. Для нескольких строк используй Ctrl или Shift.
4. Перейди в основное окно и нажми **▶ Start**. Если другая загрузка уже выполняется, материалы подписки ждут следующего запуска сессии.
5. Ненужные новые материалы можно отметить **«Пропустить»**. Пропуск не является успешной загрузкой; такой материал позже доступен для ручного добавления в очередь.

При **Output folder = `D:\Video`** и имени `Канал 123` назначение будет `D:\Video\Канал 123`. При включении **Archive by date** дата добавится перед именем подписки. Общая папка фиксируется при Start, имя подписки — при принятии URL в очередь.

### Что означают результаты и повторы

| Состояние материала | Что делать |
| --- | --- |
| «Новое» | Можно добавить в очередь или пропустить. |
| «В очереди» | Материал принят, но это ещё не подтверждение успешного скачивания. Проверь основное окно. |
| «Пропущено» | Можно позже вручную добавить в очередь. |
| «Обработано» | URL уже успешно скачан; обычная проверка не ставит его на скачивание заново. |
| «Обработано в другой подписке» | Для этого точного URL уже подтверждён успех в другой подписке. После подтверждения уведомление больше не повторяется. |

Если тот же точный URL раньше был успешно скачан обычным добавлением в очередь, общая история тоже учитывается. Подписка не обязана быть источником этой прежней загрузки. Разные адреса одного видео, включая отличающиеся параметры или регистр пути, автоматически не объединяются по ID.

Исходный набор не означает «скачано»: он только задаёт точку отсчёта и скрыт из входящих. Для намеренного повторного скачивания уже обработанного ролика используй его обычный URL. Если строки ещё нет в основной очереди, добавь URL и нажми Start. Если строка уже есть, дождись завершения текущей сессии и выбери **Retry URL** в контекстном меню Downloads либо **Download selected** в контекстном меню Queue. Подтверди повтор в диалоге истории; новая копия получает свободное имя, а прежние файлы не перезаписываются.

Кнопка **«Отменить проверку»** останавливает проверку источника, а не текущие скачивания. **«Приостановить»** исключает источник из проверок; **«Возобновить»** снова разрешает ручную проверку. Удаление подписки сохраняет файлы, обычную очередь и общую историю.

## 4. Скачивать материалы через подписку с RSS / Atom

В текущей версии RSS — **не самостоятельный источник скачивания**. Нужен URL канала или плейлиста, который yt-dlp может полностью перечислить. RSS / Atom необязательно дополняет названия подтверждённых материалов; источником состава подписки остаётся полный обход.

Для YouTube приложение может автоматически найти ленту по метаданным канала. Её можно не вводить вручную. Форма адреса ленты канала:

```text
https://www.youtube.com/feeds/videos.xml?channel_id=CHANNEL_ID
```

Здесь нужен настоящий ID канала вида `UC…`, а не `@имя`. Для другой платформы используй предоставленный ею адрес RSS / Atom, если у неё есть подходящая поддерживаемая коллекция.

1. Открой **«Подписки»**.
2. В основное поле вставь URL канала или плейлиста. В поле **«RSS / Atom (необязательно)»** вставь URL соответствующей ленты либо оставь его пустым для автоматического определения YouTube.
3. Укажи краткое имя и выбери исходный набор или импорт всех существующих материалов, как в [предыдущем сценарии](#subscriptions).
4. Нажми **«Добавить и проверить»**. Программа сначала полностью перечислит коллекцию, затем при наличии ленты прочитает её.
5. При последующих проверках нажимай **«Проверить»** или **«Проверить все»**. Новые материалы выбери во входящих, нажми **«В очередь; запуск кнопкой Start»**, затем **▶ Start** в основном окне.

**Результат:** загрузка и папки работают как у обычной подписки. Подключение ленты не включает расписание, автоматическое скачивание и проверку при запуске приложения.

У RSS есть четыре важных ограничения:

- Полный обход выполняется при каждой проверке, даже если лента не изменилась. RSS не сокращает его до списка последних публикаций.
- Лента дополняет отсутствующее название только при точном совпадении URL с полным списком. Разные варианты адреса не сопоставляются по media ID.
- Ссылка, присутствующая только в RSS, не попадёт во входящие. Поэтому в ленте канала могут быть материалы, не относящиеся к выбранному плейлисту или вкладке.
- Недоступная или некорректная лента даёт предупреждение, но успешный полный обход остаётся результатом проверки. Если не удался сам полный обход, RSS не заменит его и прежний набор не будет обновлён частичным списком.

Если у тебя есть только RSS без полностью перечисляемого канала/плейлиста, отдельная RSS-подписка в этой версии не поддерживается.

## Если что-то не получилось

При русском языке интерфейса Windows приложение показывает русские объяснения ошибок загрузки, метаданных и подписок. Региональные настройки чисел и дат на выбор языка ошибок не влияют. После изменения языка Windows перезапусти приложение.

Причину ошибки загрузки можно прочитать в подсказке состояния строки или через меню **«Показать ошибку»** в Downloads. **«Исходная диагностика»** в том же меню показывает оригинальный ответ yt-dlp для обращения за помощью. В Preview оригинал доступен в подсказке сообщения, в подписках — в подсказке строки. Журнал сохраняет исходную диагностику вместе с объяснением. Если ошибка неизвестна приложению, оно сообщит об этом по-русски; автоматического перевода произвольного текста сайта нет. При другом языке интерфейса Windows исходные сообщения остаются без перевода.

| Ситуация | Что проверить |
| --- | --- |
| Start сообщает об отсутствии FFmpeg / ffprobe | Нажми **Install FFmpeg** в Dependencies, дождись установки и повтори Start. |
| Не появляется название или обложка | Посмотри сообщение Preview и журнал. Метаданные запрашиваются в фоне; ошибка изображения не отменяет текст и не является результатом скачивания. Для WebP/AVIF-обложек нужен FFmpeg. |
| yt-dlp сообщает об ошибке доступа YouTube | При необходимости обнови **Update yt-dlp**, проверь доступность самого материала и файл Cookies. Возможность просмотра в браузере не гарантирует такой же доступ у отдельного загрузчика. |
| После первой проверки входящие пусты | При выключенном флаге импорта старых видео это ожидаемо: они стали исходным набором. Следующая проверка покажет URL, которых ещё не было в этой подписке. |
| Подписка помнит скачанный ролик, но файла уже нет | История не очищается от удаления файла. Для новой копии используй обычный URL; существующее задание можно явно повторить через **Retry URL** или **Download selected**, когда сессия не работает. |
| Полная проверка не завершается успешно | Для обычных коллекций действуют пределы 10 000 материалов, 180 секунд и 32 МиБ метаданных. Ошибка доступа, недоступный элемент или неполный список запрещают обновление исходного набора. Проверь сообщение источника; если сайт предоставляет более узкий плейлист или раздел, можно подписаться на него. |
| RSS показывает предупреждение | Полный список и лента могут содержать разные ссылки; необязательная лента также может быть недоступна. Смотри результат полного обхода, а не только ленту. |
| Файлы попали в неожиданную подпапку | Проверь краткое имя подписки и **Archive by date** после выбора профиля. Имя уже добавленного задания не меняется при переименовании подписки. |

Очередь, подписки, история и кеш находятся в `%LOCALAPPDATA%\VideoDownloader`. Открыть каталог можно кнопкой **«📁 Открыть папку настроек»**. Для резервной копии закрой приложение и сохрани весь каталог; не удаляй историю ради очистки обычной очереди. После запуска восстановление очереди не начинает скачивание без Start.
