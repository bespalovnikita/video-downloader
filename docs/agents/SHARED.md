# Общие межплатформенные контракты

Этот документ обязателен для любой задачи вместе с [CORE.md](CORE.md). Windows и Android имеют разные локальные хранилища и runtime; общий формат обмена очередью не делает их снимки совместимыми.

## Перенос очереди между платформами

- Общий контракт — [tests/fixtures/portable-queue/README.md](../../tests/fixtures/portable-queue/README.md): `VDQUEUE1:` + padded Base64 от GZIP UTF-8 JSON, версия 1. C# `PortableQueueCodec` и Kotlin `PortableQueue` должны читать одни и те же фикстуры, сохранять точные URL, Unicode-названия и порядок. Проверяй обмен пакетами в обоих направлениях; равенство GZIP-байтов не требуется.
- Переносятся только URL и названия всех строк. Не переноси статусы, историю, настройки, cookies, локальные пути, grant URI, владение файлами и связь с подписками. Создавай новые строки с `DeferredToNextStart` / `deferredNextStart`, а в Android — с новыми IDs; импорт не присоединяется к активной загрузке. Существующие строки сохраняют порядок, состояние и принадлежность; допускается дополнение пустого названия.
- Проверяй весь пакет до применения: точные дубли объединяются с сохранением первой записи. Семейство `VDQUEUE` распознавай до обычного извлечения URL, чтобы неизвестная версия или повреждённый пакет отклонялись целиком. Не импортируй переносимую очередь через Watch clipboard без явного действия пользователя.
- Ограничения: 100 000 входных записей до дедупликации, 16 МиБ JSON и сжатых данных, глубина 32, 24 МиБ входного текста; строгие UTF-8, Unicode и Base64. Общий предел экспорта в буфер — 262 144 символа; для больших пакетов и ошибок записи буфера предлагай `.vdqueue`. Сжатие и разбор выполняй вне UI thread; распаковку ограничивай во время чтения.
- Изменения общего формата или фикстур требуют Windows и Android CI, unit-тестов в обеих реализациях и реальных UI-сценариев явного копирования/вставки. Сохраняй импорт обычных URL, TXT и InternetShortcut. Пользовательские действия описаны в [руководстве по переносу очереди](../user/queue-transfer.md).

## Границы общего контракта

- Не переноси Windows `session.json`, `subscriptions.json` и `successful-downloads.jsonl` как Android `state.json` или наоборот. Импорт очереди — отдельное явное действие, а не импорт локального владения и истории.
- Проверяй точные URL, Unicode, порядок, дубли, повреждённый пакет, неизвестную версию и превышение лимитов по [общим фикстурам](../../tests/fixtures/portable-queue/README.md). Обычный URL/TXT/InternetShortcut не должен перестать импортироваться из-за поддержки `VDQUEUE`.
- Общий коллектор находится в [`collection-plugins/`](../../collection-plugins/); изменение его поведения требует Windows и Android CI. Windows передаёт режим recent явно; Android использует полный обход. Подробные ограничения адаптера перечислены в [WINDOWS.md](WINDOWS.md#подписки-текущий-контракт) и действуют при изменении общего Python-кода.
- Допустимые расхождения интерфейсов и внутреннего хранения описывай явно. Не обещай мобильному клиенту проверенное окно Windows, автоматический планировщик или полное совпадение функций, пока это не реализовано и не проверено.
