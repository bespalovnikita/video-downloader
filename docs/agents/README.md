# Документация для агентов

Начинай с [корневого AGENTS.md](../../AGENTS.md). Он задаёт обязательные чтения по путям задачи; этот каталог хранит подробные контракты, которые нельзя терять при рефакторинге.

| Документ | Когда читать |
| --- | --- |
| [CORE.md](CORE.md) | Всегда: общие инварианты, проверки, Git workflow, релизные ограничения |
| [SHARED.md](SHARED.md) | Всегда: точные URL, границы локальных данных, формат `VDQUEUE1`, общие коллекторы |
| [WINDOWS.md](WINDOWS.md) | C#, WPF, Windows runtime, хранение и совместимость, preview, подписки, Windows CI и пакет |
| [ANDROID.md](ANDROID.md) | Kotlin, Compose, runtime, foreground service, публикация, backup, Android CI и APK |
| [DOCUMENTATION.md](DOCUMENTATION.md) | Любые Markdown-правки и синхронизация документации при изменении поведения |

Для реализации используй [архитектуру](../developer/architecture.md), [матрицу тестов](../developer/testing.md) и [инструкцию по изменениям](../developer/contributing.md). Фактические действия пользователя описаны в [русских руководствах](../user/README.md). Идеи будущего развития отделены в [планах проекта](../project/README.md).

Документы этого каталога являются продолжением обязательных инструкций корневого `AGENTS.md`, а не альтернативным набором рекомендаций. Они не добавляют вложенных `AGENTS.md` и не меняют область действия существующих полномочий пользователя.
