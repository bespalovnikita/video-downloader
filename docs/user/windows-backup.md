# Резервная копия профиля Windows

[Windows: сценарии](windows.md) · [Справочник](windows-reference.md) · [Решение проблем](troubleshooting.md#windows-backup)

Кнопка **«Резервная копия…»** в Windows сохраняет один файл `.vdbackup` для переноса настроек, подписок и истории успехов на другой компьютер. Это отдельный формат Windows. Для обмена очередью с Android используй [`.vdqueue`](queue-transfer.md).

## Создать копию

1. Дождись завершения загрузок, проверки подписок, очистки файлов и обновлений.
2. Нажми **«Резервная копия…»**, затем **«Создать копию…»**.
3. Выбери локальную папку и новое имя файла. Существующий файл не перезаписывается: выбери другое имя.
4. Проверь показанный состав и число пропущенных приватных адресов. Сохрани видео отдельно.

Копия содержит выбранный встроенный профиль и переносимые параметры качества, кодеков, контейнера, языков, субтитров и относительного шаблона имени; источники и материалы подписок; точные URL, названия, источник и время подтверждённых успехов. Именованных пользовательских профилей в приложении пока нет.

В архив не входят очередь, выбор форматов и фрагментов отдельных строк, скачанные файлы, права на их открытие или удаление, локальные пути, cookies, разрешение следить за буфером, кеш, журналы, SDK и файлы обновления. Адреса с паролем, приватными query-параметрами либо фрагментом исключаются целиком; счётчики отдельно показывают подписки, материалы, историю и RSS. Сохраняемые URL остаются точными, включая регистр и известные публичные параметры. Приватные сведения в описательном тексте скрываются, число изменённых полей также показывается.

## Восстановить на этом или новом компьютере

1. Открой **«Резервная копия…» → «Открыть копию…»** и выбери локальный `.vdbackup`. Сетевой файл сначала скопируй на компьютер.
2. Прочитай состав, пропуски и ожидаемые изменения. До подтверждения данные не меняются.
3. Выбери **«Объединить с текущими подписками»** либо **«Заменить только подписки»**. Первый режим сохраняет текущие источники и добавляет недостающие; второй заменяет только список подписок и их материалов.
4. Нажми **«Перейти к подтверждению»**, проверь изменения и нажми **«Подтвердить восстановление»**. **«Вернуться к просмотру»** отменяет этот шаг без записи.

Переносимые настройки применяются из копии. Папка вывода, файл cookies и разрешение следить за буфером сохраняются с текущего компьютера; на новом компьютере задай их отдельно. История всегда объединяется, прежние локальные записи сохраняются. Импортированная история подтверждает прошлый успех, но не предоставляет доступ к файлам старого компьютера.

Текущая очередь, её привязки к файлам и сами медиафайлы сохраняются. Состояние «В очереди» у импортированных материалов становится «Новое»: восстановление не добавляет задания в очередь, не запускает проверку источников или скачивание. Для переноса очереди есть отдельный `.vdqueue`.

## Проверка и прерванное восстановление

До предварительного просмотра проверяются схема, все разделы ZIP, SHA-256, допустимые пути и типы записей, размеры, степень сжатия, уникальность записей и отсутствие приватных данных. Повреждённый или неизвестный формат целиком отклоняется. Пределы: архив до 64 МиБ, раздел до 32 МиБ, до 100 000 записей каждого вида.

Запись профиля выполняется с локальными прежними копиями и журналом восстановления. Отмена или ошибка до завершения возвращает прежнее согласованное состояние; после аварийного завершения процесс восстановления выполняется при следующем запуске до чтения профиля. Не удаляй служебные `.profile-restore*` самостоятельно. Если внешний процесс изменил один из файлов либо откат не завершён, запись блокируется: сохрани исходный каталог и диагностику, затем перезапусти приложение. При повторной ошибке обратись за помощью, сохранив данные.

Если уже повреждён текущий `session.json`, `subscriptions.json` или история, импорт не перезаписывает их молча. Сначала полностью закрой приложение и сохрани исходный каталог для диагностики; исправление повреждённых данных требует отдельного решения. [Подробности](troubleshooting.md#повреждённые-данные-или-ошибка-сохранения).
