# Руководства пользователя

Выбери свою платформу: [Windows — установка и четыре сценария скачивания](windows.md) или [Android — установка APK и работа на телефоне](android.md). Подписки проверяются вручную, а принятые материалы ждут кнопки **Start**.

| Задача | Инструкция |
| --- | --- |
| Скачать одно видео YouTube в Windows | [Одно видео](windows.md#youtube-video) |
| Скачать плейлист отдельными заданиями в Windows | [Плейлист YouTube](windows.md#youtube-playlist) |
| Следить за каналом или коллекцией в Windows | [Подписки](windows.md#subscriptions) |
| Добавить RSS / Atom к коллекции | [Windows](windows.md#rss), [Android](android.md#подписка-и-rss) |
| Скачать видео, плейлист или подписку на Android | [Руководство Android](android.md) |
| Найти настройку Windows, шаблон имени, превью или действие строки | [Справочник интерфейса Windows](windows-reference.md) |
| Подключить браузерную сессию для закрытого материала | [Экспорт и импорт cookies](cookies.md) |
| Перенести очередь на другой компьютер или телефон | [Копирование очереди и файлы .vdqueue](queue-transfer.md) |
| Разобрать прогресс, журнал или пропавшую обложку | [Журнал Windows](windows-logging.md), [прогресс Android](android.md#прогресс-и-время-сессии), [журнал Android](android.md#журнал-и-диагностика) |
| Обновить приложение, сохранить данные или исправить ошибку | [Практические рецепты](troubleshooting.md) |

Для первого запуска достаточно выбрать папку, добавить URL и нажать **Start**. В Windows предварительно проверь **Dependencies** и установи FFmpeg при необходимости; в Android компоненты входят в APK. Ни обложка, ни появление строки в очереди не означают, что видео уже скачано: история успехов пополняется после проверки и сохранения готового файла.

## Чем различаются версии

Общий обмен между платформами — [переносимая очередь](queue-transfer.md): URL, названия и порядок. Подписки, настройки, история, разрешения папок и cookies хранятся отдельно. Наличие функции в Windows не означает, что она уже перенесена на телефон.

| Возможность | Windows | Android |
| --- | --- | --- |
| Распространение | Portable ZIP в GitHub Releases | Release APK с постоянной подписью в том же GitHub Release |
| Ручная проверка подписок | Быстрое окно для подтверждённых источников с полным обходом при необходимости; можно принудительно обойти всё | Проверенное окно до 20 публикаций для подходящих источников; полный обход при необходимости или по флажку «Полная проверка» |
| Приём новинок | Общий вопрос после проверки нескольких источников или выбор строк | Общий вопрос после проверки успешных источников или выбор строк |
| Существующие видео без первоначального импорта | Видны как «Исходный снимок», можно принять выбранные в очередь | Видны в «Исходный набор» и «Все», можно принять выбранные в очередь |
| Просмотр материала подписки | Правая панель со сведениями и до двух обложек | Окно со сведениями и до двух изображений; можно раскрыть полную галерею |
| Предварительная догрузка обложек после проверки | Для всех состояний материалов, независимо от приёма в очередь | Для всех состояний в подтверждённой области проверки, независимо от приёма в очередь |
| Новые обычные URL во время скачивания | Могут присоединиться к активной сессии | Add/Paste и «Поделиться» могут присоединиться к той же сессии после проверки истории; пауза сохраняется, подписки и импорт ждут Start |
| Работа при сворачивании | Системный трей Windows | Foreground service с уведомлением и системными ограничениями Android |
| Прогресс и время | Общий прогресс компонентов; время фиксируется после завершения сессии | Общий прогресс компонентов и коллекции при известном плане; время принадлежит foreground service и фиксируется после завершения работников и очистки |
| Журнал | Четыре профиля, копирование, сохранение и файлы с ротацией | Четыре профиля, копирование, сохранение через системный диалог и приватные файлы с ротацией |

Объём четырёх этапов и сохраняющиеся особенности платформ описаны в [матрице Android и Windows](../project/ANDROID_PARITY.md). Идеи развития — в [дорожной карте](../project/ROADMAP.md).

Для переноса настроек, подписок и истории между Windows-компьютерами есть отдельная [резервная копия `.vdbackup`](windows-backup.md). Она сохраняет текущую очередь и локальные пути при восстановлении; Android использует свой формат резервного состояния.
