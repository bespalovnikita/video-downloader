# Windows: справочник интерфейса

Этот справочник относится к Windows 10/11 x64. [Каталог пользовательских инструкций](README.md).

Пошаговые кейсы для YouTube, плейлистов, подписок и RSS находятся в
[руководстве пользователя](windows.md). Взаимодействие компонентов и
жизненные циклы показаны в [архитектурных диаграммах](../developer/architecture.md).

Запусти `VideoDownloader.exe` из полностью распакованного Windows ZIP. Интерфейс работает на C# / .NET 8 / WPF; PowerShell, Python и установленный .NET Runtime пользователю не нужны. Папки `ui/`, `assets/`, `collection-plugins/`, `yt-dlp.exe` и `windows-package.json` должны оставаться рядом с приложением.

Запуск EXE с URL, `.txt`, `.url`, `.vdqueue` или адресом `videodownloader://` добавляет материалы в интерфейс. Если окно уже открыто или спрятано в трей, аргументы получает существующий экземпляр. Загрузки запускаются из окна.

## Ширина панелей

При первом запуске ширина **«Очередь»** — около 507 px. Перетаскивай вертикальные разделители между **Очередь / Загрузки** и **Загрузки / Предпросмотр**, чтобы изменить ширину панелей. Размеры сохраняются вместе с настройками. Панель «Загрузки» занимает оставшееся место; при уменьшении окна сохранённые размеры подстраиваются так, чтобы панели оставались доступны.

## Очередь ссылок

### Поиск и фильтры

Поиск и фильтры по умолчанию свёрнуты. Нажми кнопку с лупой в заголовке очереди, чтобы открыть **«Поиск в очереди»**, фильтр статуса и фильтр подписки. Повторное нажатие освобождает место для списка, сохраняя введённый запрос и фильтры. Число возле лупы показывает количество применённых условий, в том числе при закрытой панели. Видимость панели и сами условия не сохраняются между запусками.

Поиск находит часть названия или исходного URL без учёта регистра. Строки с URL, отличающимися регистром, по-прежнему остаются разными заданиями. Подписки с одинаковыми названиями различаются по закреплённому идентификатору; **«Без подписки»** выбирает обычные ссылки. Счётчик **«Показано … из …»** показывает видимое и общее число строк. При отсутствии совпадений список объясняет, что нужно изменить поиск или сбросить фильтры.

**Ctrl+F** раскрывает панель и переводит фокус в поиск. **«Сбросить фильтры»** или **Esc** в поиске возвращают полный список. Фильтры не меняют очередь, её порядок, историю, папки и активную сессию. Список фрагментов внутри строки, их порядок и уже сохранённые результаты также сохраняются. Новое название или изменившийся статус обновляют видимость строки. Пока включён фильтр, изменение порядка стрелками и перетаскиванием отключено даже при закрытой панели; сначала сбрось фильтры.

**«Удалить выбранные»** и команды меню **«Скачать выбранные строки» / «Удалить выбранные строки»** относятся только к выделенным видимым строкам. Строка, скрытая новым фильтром, перестаёт быть выделенной. Удаление начатого или готового задания по-прежнему требует отдельного подтверждения и использует прежние правила владения файлами.

Кнопки **«▶ Скачать всю очередь»**, **«Повторить ошибки»** и **«Очистить всю очередь»** действуют на все подходящие задания, включая скрытые. Подтверждение очистки показывает общее, видимое и скрытое число строк; оно удаляет записи, а не скачанные файлы. Строки, поступившие после появления вопроса, сохраняются и требуют нового подтверждения. Копирование и экспорт также переносят полную очередь. **«Вставить»**, **«+ Добавить»** и получение ссылок продолжают работать при фильтрации; новая строка может сразу оказаться скрытой, о чём сообщает подсказка.

### Добавление и отображение

Под очередью находится переключатель **«Показывать названия видео вместо URL»**. Он меняет подписи в очереди и списке загрузок: выключен — видны URL, включён — названия видео. Пока метаданные загружаются или название недоступно, остаётся URL. Названия подхватываются из фонового превью и кеша без дополнительного запроса при переключении. Исходная ссылка всегда доступна в подсказке и действиях строки. Выбранный режим и полученные названия сохраняются между запусками.

Можно добавлять:

- одну ссылку или несколько HTTP/HTTPS-ссылок в поле ввода;
- содержимое буфера через **«Вставить»**; при включении **«Следить за буфером обмена и добавлять ссылки»** ссылки добавляются автоматически;
- `.txt` со списком URL и Windows `.url` кнопкой **«Открыть список»**;
- ссылки и файлы перетаскиванием в окно.

Повторяющиеся URL в очередь не добавляются. До запуска доступны изменение порядка мышью и стрелками, кнопки **«Удалить выбранные»** и **«Очистить всю очередь»**. Во время активной загрузки очередь остаётся доступной для выбора, просмотра превью, открытия и копирования URL.

Двойной щелчок левой кнопкой по успешно скачанной строке **«Очередь»** открывает её локальный медиафайл в приложении Windows по умолчанию. Для незавершённой строки или уже отсутствующего файла действие не выполняется.

**Новые обычные ссылки во время скачивания** поступают в асинхронную очередь текущей сессии. Если сессия уже закончилась, новая ссылка останется в очереди до следующего запуска. Материалы из подписок и импортированной переносимой очереди всегда ждут следующего нажатия **«Скачать всю очередь»**.

### Перенос очереди на другое устройство

Кнопка **«Перенос очереди»** открывает команды **«Копировать очередь»**, **«Вставить очередь»**, **«Сохранить очередь в файл…»** и **«Открыть файл очереди…»**. Текст и файл `.vdqueue` совместимы с Android-клиентом. Кнопка **«Вставить»** также распознаёт переносимую очередь; **«Следить за буфером обмена и добавлять ссылки»** не импортирует её автоматически.

Переносятся все строки с URL и названиями в их порядке. Новые ссылки дополняют очередь и ждут **«Скачать всю очередь»**; существующие сохраняют состояние. Прогресс, скачанные файлы, cookies, настройки, выбранные форматы и фрагменты, история и связь с подписками не переносятся. Для текста длиннее 262 144 символов используй файл. Пошаговые действия — в [инструкции переноса](queue-transfer.md).

### Кнопка открытия папки загрузок

В верхней части очереди **сразу рядом с «Повторить ошибки»** находится кнопка **«📂 Открыть папку загрузок»**. Она не зависит от выделения файла в таблице и не удаляет файлы.

Папка берётся из поля `Папка загрузок`. При включённом `Архив по дате` открывается датированная подпапка вида `D:\Videos\2026-10-20`. При активном скачивании используется **зафиксированный каталог текущей сессии**, чтобы переход через полночь не переключал папку.

Если каталог ещё не создан, приложение показывает предупреждение вместо открытия чужой родительской папки. Чтобы изменить каталог, используй поле `Папка загрузок` или кнопку с многоточием рядом с ним.

Отдельная кнопка `Показать в папке` в таблице результатов продолжает открывать **папку конкретного скачанного файла**; эти действия не следует путать.

### Удаление и отмена конкретного задания

Кнопка **«Удалить выбранные»** доступна во время скачивания. Она отменяет только выбранный URL, не останавливая остальные задания. Для начатых и завершённых загрузок запрашивается подтверждение удаления связанных файлов. Приложение удаляет только файлы, принадлежность которых конкретному заданию подтверждена.

Файлы других заданий и ранее существовавшие результаты сохраняются. Для старой записи одного сохранённого пути недостаточно, чтобы автоматически удалить файл. Не перенаправляй папки и не перемещай результаты во время удаления.

Строка активного задания остаётся до завершения процесса и подтверждения очистки работником. Если файл заблокирован или не хватает прав, приложение показывает ошибку и сохраняет строку для повторного нажатия «Удалить выбранные». Исходная папка вывода хранится у задания: смена поля `Папка загрузок` после скачивания не меняет границы удаления старого результата.

После подтверждённого удаления повторное добавление того же URL в ещё работающий сеанс оставляет его в состоянии «В очереди» до следующего запуска. Пока отмена не подтверждена, строка остаётся в очереди и повторно не добавляется.

Незавершённая очистка сохраняется между запусками. Такие строки исключаются из запуска и повтора скачивания и сохраняются при очистке всей очереди. После восстановления приложения можно снова нажать «Удалить выбранные». Если приложение сообщает, что владение старым файлом не подтверждено, проверь и удали нужный файл вручную, затем снова нажми «Удалить выбранные».

Удаление файла не удаляет соответствующий URL из постоянной истории успешных загрузок.

## Список загрузок

В **Downloads** активные задания всегда находятся выше остальных. Это относится к запуску, скачиванию, повтору, обработке и публикации результата; общая пауза сохраняет их в верхней части списка. После завершения, ошибки или прерывания строка переходит в нижнюю часть. При нескольких активных заданиях сохраняется порядок их появления в списке.

Щелчок по заголовку колонки сортирует строки внутри каждой из двух частей списка; повторный щелчок меняет направление. **Shift + щелчок** добавляет колонку к сортировке. Активные строки остаются сверху при любом направлении. Выделение и действия относятся к тому же заданию после его перемещения; изменение скорости и прогресса само по себе не переставляет строки. Порядок очереди, запуска работников и нумерация материалов плейлиста от этой сортировки не меняются. Выбранная сортировка действует до закрытия приложения.

## Профили загрузки

В поле **«Профиль»** названия показываются на русском:

| Название | Основные настройки |
| --- | --- |
| **Универсальный** | Максимально доступное качество и автоматические параметры |
| **Архив 4K** | До 2160p, контейнер MKV, метаданные и главы |
| **Совместимый MP4** | До 1080p, предпочтение H.264, контейнер MP4 |
| **Музыка MP3** | Извлечение звука, метаданные и обложка |
| **Архив с субтитрами** | MKV, субтитры, автосубтитры и встраивание |

Профили применяют готовые наборы полей. Ты можешь вручную изменить любое поле после выбора профиля. Создание собственных именованных профилей пока не предусмотрено. Выбор профиля полностью задаёт качество, кодек, контейнер, обычные и автоматические субтитры, встраивание данных и режим только аудио. «Архив 4K» включает архивирование в подкаталог даты; остальные профили его отключают. Пути, cookies, скорость, число работников и прочие параметры соединения не меняются. Настройки восстанавливаются независимо от наличия очереди, а восстановление самих строк требует подтверждения; это не глобальные пользовательские профили.

До скачивания программа проверяет FFmpeg и ffprobe. При отсутствии зависимостей установи их кнопкой **«Установить FFmpeg»** в **«Компоненты»** и снова нажми «Скачать всю очередь». Передача медиа до этой проверки не начинается.

Контейнер MP4/MKV/WebM применяется и к одиночному файлу. Для несовместимых кодеков возможна ошибка remux: автоматическое перекодирование не выполняется. При разрешённой повторной загрузке новая копия получает свободное имя с `(2)`, `(3)` и далее; субтитры сохраняют тот же суффикс. Удаление копии сохраняет прежние результаты.

**Совместимость с предыдущими версиями:** в файле `session.json` имена по-прежнему сохраняются как `Universal`, `4K archive`, `MP4 compatibility`, `Music MP3` и `Subtitles archive`. При открытии старой сессии они преобразуются в русские названия.

## Папка настроек приложения

В разделе **«Компоненты»** рядом с **«Зарегистрировать протокол»** находится кнопка **«📁 Открыть папку настроек»**.

Она открывает в Проводнике:

~~~text
%LOCALAPPDATA%\VideoDownloader
~~~

Обычно это `C:\Users\<имя>\AppData\Local\VideoDownloader`. Используется именно **Local**, а не `%APPDATA%` (`Roaming`).

Содержимое:

| Путь | Назначение |
| --- | --- |
| `session.json` | Сохранённая очередь и параметры |
| `subscriptions.json` | Подписки, исходные наборы и входящие |
| `successful-downloads.jsonl` | Постоянная история успешных URL |
| `preview-cache\` | Кеш метаданных и изображений |
| `logs\` | Автоматические файлы журнала |

Если директория настроек ещё не существует, кнопка создаёт её и открывает. Сама кнопка ничего не удаляет и не сбрасывает. Прежде чем вручную менять эти файлы, закрой программу и сделай резервную копию.

## Предпросмотр

В панели **«Предпросмотр»** отображаются заголовок, автор, продолжительность, обложка, платформа, доступное разрешение, частота кадров, кодеки и HDR (если эти сведения предоставлены сайтом).

Для каждого точного URL программа получает и кеширует **до 15 изображений сайта**. Если сайт отдал меньше пригодных изображений, галерея будет меньше; одинаковые по содержимому картинки не дублируются. Обложка может быть выбранной автором картинкой. Проверка времени начала и конца находится отдельно в окне [«Формат и фрагмент…»](#формат-и-фрагмент-отдельного-видео).

Если после успешного скачивания пригодной обложки нет или кешированная картинка повреждена, программа в фоне получает один кадр из сохранённого видео через FFmpeg и ffprobe. Обычно берётся точка около 10% длительности, не дальше трёх секунд; при необходимости проверяется начало. Это происходит и для невыбранной строки, без повторного **Start**. При запуске ограниченно проверяются до 256 сохранённых завершённых строк с подтверждёнными собственными файлами. Путь из импортированной истории сам по себе такого доступа не даёт. Готовая обложка сайта сохраняется. Аудиофайл, вложенная картинка аудио, повреждённое или неподдерживаемое видео могут остаться без изображения; это не отменяет успешное скачивание.

Кадр сохраняется только в общем кеше предпросмотра: сам видеофайл и файлы рядом с ним не меняются. Для локального кадра отводится до 20 секунд, размер — до 640 × 360 пикселей и 1 МиБ. Отсутствие FFmpeg/ffprobe или другая ошибка отражается в журнале. Удаление результата, обновление компонентов и закрытие приложения сначала отменяют такую фоновую работу и дожидаются освобождения файла. Локальный кадр не продлевает срок метаданных сайта и не меняет историю загрузок. После ошибки обложки её можно снова получить с сайта при следующем обращении через минуту; запасной кадр остаётся видимым до готовности обложки.

yt-dlp может вернуть варианты в `thumbnails` и отдельный адрес `thumbnail`. Программа убирает повторы адресов, сначала рассматривает ссылки с расширениями JPG/JPEG/PNG, затем внутри каждой группы — картинки с большей площадью `width × height`. Проверяются до 60 кандидатов, пока не набраны 15 разных пригодных изображений или не исчерпан бюджет запроса. Адреса без расширения тоже допустимы. Несколько вариантов могут быть разными разрешениями одной обложки; различие содержимого видео между картинками не гарантируется.

Наведи мышь на изображение в панели «Предпросмотр»: доступные картинки начнут листаться по кругу каждые 0,9 секунды. Колесо мыши и кнопки **‹ / ›** переключают их вручную, счётчик показывает текущий номер. После ухода мыши автоматическое листание останавливается. Листание использует уже полученные изображения и не запускает сеть. Название и первая картинка появляются сразу по готовности; оставшаяся галерея дополняется в фоне.

**«Встроить обложку»** — отдельная настройка скачивания: она поручает yt-dlp сохранить и встроить обложку в поддерживаемый медиафайл. Изображение при этом выбирает сам yt-dlp; картинка из кеша предпросмотра ему не передаётся, поэтому совпадение не гарантируется. Приложение не запрашивает сохранение всех обложек и не управляет несколькими вложенными изображениями файла. Миниатюру в Проводнике Windows создаёт отдельный обработчик Windows, она также может отличаться от предпросмотра.

Запрос метаданных и обложки ставится в фоновую очередь сразу после добавления URL, без запуска скачивания и выбора строки. Единственный работник обрабатывает её последовательно: время получения зависит от сайта и предыдущих запросов. При выборе URL без готового превью эта ссылка получает приоритет. При нажатии «Вставить» приложение выбирает добавленную ссылку и начинает показывать её превью, когда данные готовы; Следить за буфером обмена и добавлять ссылки сохраняет текущее выделение.

После успешной проверки подписки в ту же очередь ставится фоновая догрузка недостающих обложек независимо от состояния материала: исходный снимок, новые, поставленные в очередь, обработанные и пропущенные видео. Полный обход использует список материалов, подтверждённых текущим результатом; быстрое окно — весь сохранённый набор подписки. Актуальные готовые данные используются из кеша без повторного HTTP-запроса. Догрузка не задерживает завершение проверки или общий вопрос о добавлении новинок, не меняет состояния и не скачивает медиафайлы.

Отказы отдельных запросов видны в журнале: адрес видео, адрес проверяемой картинки, номер кандидата, этап, HTTP-статус при наличии ответа, объём и причина ошибки. Проверка и очередь продолжают работу. Правила кеша остаются прежними: до 72 часов для пригодных данных и ответа без изображений, возможность повторить пустой результат после ошибки через минуту при следующем обращении.

На один предпросмотр отводится не более 30 секунд, включая процесс yt-dlp и чтение изображений. Вся галерея дополнительно ограничена общими 12 секундами, размером 2 МБ на изображение и 12 МБ на набор. При таймауте сохраняются уже полученные картинки и текстовые метаданные; очередь предпросмотра продолжает работу. Внешние конфигурации yt-dlp игнорируются и при предпросмотре.

При добавлении из подписки уже найденное название сразу переносится в очередь и в панель предпросмотра выбранного видео, даже если ссылка уже была в очереди. Оно остаётся видимым, если полный запрос метаданных или обложки не удался. Повторное принятие уже существующей строки из подписки также запрашивает превью: после ошибки полного запроса не нужно выбирать строку для повторения. Готовый кеш и уже выполняющийся запрос используются повторно. При восстановлении сохранённой очереди пропущенные названия берутся из списка соответствующей подписки. Для отображения названий в таблицах включи **«Показывать названия видео вместо URL»**. Ошибка полного запроса завершает состояние загрузки и показывает причину в панели; повторный выбор ссылки без готового кеша позволяет повторить запрос.

Адрес обложки может не иметь расширения файла: приложение проверяет декодирование изображения, перебирая подходящие варианты в пределах общего лимита миниатюры. Повреждённая картинка не блокирует запасной вариант. Допустимый исходный размер — до 16 777 216 пикселей; отображаемая обложка ограничена 720 пикселями по большей стороне без увеличения маленьких изображений. Для WebP/AVIF используется установленный FFmpeg, который преобразует локально полученные байты в PNG. Если нужного декодера нет, название и остальные метаданные всё равно сохраняются. Старые записи кеша с ошибкой `no JPEG/PNG thumbnail was provided by yt-dlp` обновляются при следующем запросе.

Кеш действует до 72 часов в папке `preview-cache` внутри каталога настроек. Если картинки нет из-за ошибки её получения, следующий запрос может обновить результат через минуту; автоматического таймера повтора нет. Успешная обложка и ответ сайта без изображений сохраняют обычный срок кеша. Отсутствующий FFmpeg не вызывает повторов до его установки. Служебные записи автоматически вытесняются, когда дисковый кеш превышает примерно 512 МиБ; они могут быть получены заново. Ссылки сопоставляются точно, с учётом регистра пути и параметров. Повреждённые изображения и устаревшие записи обновляются при следующем запросе. Прежний кеш с одной обложкой остаётся пригодным и дополняется галереей при обращении к URL. Ошибка записи на диск не мешает показать уже полученные данные.

Некоторые сайты могут требовать cookies. Путь к файлу задаётся в `Cookies`, а не содержимое cookies непосредственно в программе. См. отдельную [инструкцию по экспорту из браузера и подключению cookies](cookies.md). Ошибки получения метаданных выводятся в лог.

Если во время диалога повтора та же ссылка приходит из буфера или через протокол, она остаётся в очереди в одном экземпляре. Если текущая сессия успела завершиться, подтверждённая ссылка ждёт следующего запуска скачивания.

Сохранённые настройки применяются и при пустой или полностью завершённой очереди, даже если восстановление строк отклонено. Скачивание ZIP установщика FFmpeg ограничено шестью минутами, включая тело ответа; при таймауте кнопки зависимостей снова доступны.

## Подписки на каналы и плейлисты

Кнопка **«Подписки»** в основном окне открывает отдельное окно. Обычной очередью можно продолжать пользоваться, пока идёт проверка источника.

Для выбранного источника поле **«URL подписки»** показывает его исходный адрес. Его можно выделить и скопировать через Ctrl+C либо нажать **«Копировать URL»**; проверка подписки не блокирует копирование.

### Добавление источника и первая проверка

1. Укажи HTTP/HTTPS-ссылку на канал или плейлист. Поддерживается любой сайт, для которого установленная версия `yt-dlp` может полностью перечислить такую коллекцию; отдельного ограничения только на YouTube нет.
2. При необходимости укажи RSS/Atom. Для YouTube приложение может получить адрес ленты из метаданных канала. Этот шаг необязателен.
3. При необходимости задай краткое имя подписки. Если оставить поле пустым, первая успешная проверка возьмёт название канала или автора, а при его отсутствии — название коллекции.
4. Выбери, что сделать с существующими материалами при первой успешной проверке. Флаг называется **«Добавить все существующие материалы в очередь (без скачивания)»**. По умолчанию они становятся исходным набором, видны со статусом **«Исходный снимок»** и не добавляются в очередь. Включённый флаг добавления существующих материалов отправляет их в обычную очередь, ожидающую запуска скачивания.
5. Нажми **«Добавить и проверить»**. Первая проверка выполняется в фоне. Если она не завершилась успешно, источник остаётся для повторной проверки, а исходный набор не считается установленным.

При последующих проверках новые материалы появляются во входящих. Дата публикации и позиция в плейлисте не используются как единственное доказательство новизны: список сравнивается по точным URL внутри конкретной подписки.

### Краткое имя и папка подписки

Полное название коллекции остаётся в списке подписок, а краткое имя определяет подпапку для её материалов. Например, при `Папка загрузок = D:\Video` подписка «123» скачивается в `D:\Video\123`. Если включено `Архив по дате`, путь будет `D:\Video\ГГГГ-ММ-ДД\123`. Обычные ссылки сохраняются в выбранную папку вывода с учётом настройки даты.

Чтобы переименовать подписку, выбери её, измени краткое имя и сохрани. Недопустимые для Windows символы заменяются, лишние пробелы убираются, слишком длинное имя сокращается до 80 символов. После сохранения поле показывает имя, которое будет использовано для папки. Повторная проверка не меняет его вслед за названием канала.

Краткое имя закрепляется за новым заданием при добавлении в очередь, а общая папка вывода выбирается при запуске скачивания. Переименование подписки действует на последующие добавления: уже поставленные задания сохраняют прежнее имя, а скачанные файлы остаются на месте. Если точный URL уже есть в обычной очереди, добавление из подписки сохраняет прежнее назначение этого задания. Краткое имя сохраняется при перезапуске и читается из прежних пользовательских данных.

### Проверка и действия со входящими

Можно проверить выбранную подписку или все активные, отменить текущую проверку, поставить подписку на паузу и удалить её. Флажок **«Полная проверка»** перед запуском **«Проверить»** или **«Проверить все»** принудительно включает полный обход выбранных источников; по умолчанию выключен. Пауза исключает источник из общей проверки; возобновление само по себе не запускает загрузку. Удаление подписки удаляет её записи и входящие, сохраняя скачанные файлы, постоянную историю и обычную очередь.

Во время проверки над списком подписок появляется карточка прогресса: текущий источник, этап, прошедшее время и число завершённых проверок из выбранных. Общая шкала учитывает источники, а анимированная полоса показывает работу с текущим источником. Этапы различают окно новых публикаций, переход к полному обходу, разбор списка, необязательную RSS/Atom, сравнение и сохранение результата, а при первом импорте — добавление в очередь. Число материалов появляется после разбора результата; до этого процент внутри коллекции не вычисляется. Число в быстром режиме относится к проверенному окну, а не ко всему архиву. При получении данных карточка также показывает фактически полученный объём. Итог остаётся видимым после завершения, ошибки или отмены; анимация и отсчёт времени останавливаются. Отмена и закрытие окна сохраняют прежние результаты незавершённого обхода.

После окончания всей проверки окно **«Новые материалы подписок»** одним вопросом предлагает добавить в очередь материалы со статусом **«Новое»** из успешно проверенных источников. Это относится и к **«Проверить все»**: не нужно открывать каждую коллекцию отдельно. Предложение включает ранее найденные и пока не принятые новинки; сводка показывает число материалов, разных URL и подписок. **«Добавить в очередь»** отправляет их в общую очередь; новые задания получают подписку и её краткое имя, а уже имеющиеся URL сохраняют прежнее назначение. **«Не сейчас»** или закрытие вопроса оставляет **«Новое»**. Источники с ошибкой исключаются; после отмены проверки вопрос не появляется. Исходный снимок, пропущенные и уже обработанные материалы этим предложением не принимаются. Первичный импорт существующих видео обрабатывается отдельно по выбранному при добавлении флажку. Загрузки ждут **«Скачать всю очередь»**, в том числе при работающей сессии.

Для выбранных материалов доступны действия:

- **В очередь** — добавить ссылки в обычную очередь; запуск производится кнопкой **«Скачать всю очередь»**. Даже при работающей сессии это задания следующего запуска, без добавления в live ingress. Если материал удалён из обычной очереди до успешной загрузки, его можно добавить повторно из подписки той же кнопкой.
- **Пропустить** — сохранить решение не добавлять материал в очередь. Это не успех скачивания.
- **Открыть** — открыть исходный URL в браузере.

**«Входящие и результаты»** показывают все сохранённые материалы выбранной подписки, включая **«Исходный снимок»**. Исходные видео можно выделить и вручную добавить в очередь; открытие списка их не загружает. Старые записи исходного набора видны без повторной проверки. Записи различают исходный набор, новые материалы, добавленные в очередь, успешно обработанные, уже обработанные в другом источнике и пропущенные пользователем. Повторная проверка не создаёт ещё одну запись с тем же точным URL в той же подписке. Различающиеся URL одного видео считаются разными записями.

Нажатие на один материал заполняет правую панель: название, точный URL видео, подписка, состояние и время обнаружения видны сразу. Автор, длительность, источник и доступные форматы добавляются по мере получения метаданных, а ниже показываются **до двух пригодных превью сайта**. Если доступна только одна картинка, выводится одна; ошибка изображения сохраняет текстовые сведения. Кнопки **«Открыть URL»** и **«Копировать URL»** относятся к выбранному видео. URL в поле также можно выделить и скопировать.

Вертикальный разделитель меняет ширину правой панели; при недостатке высоты она прокручивается. Выделение нескольких материалов или снятие выделения очищает сведения. Выбор здесь не переключает содержимое панели «Предпросмотр» основного окна. Правая панель использует тот же кеш и единственного фонового работника: готовые данные показываются без повторной загрузки, незавершённый запрос получает приоритет. Дополнительный работник и скачивание видео при выборе не запускаются.

Материалы идут в порядке, полученном от источника через yt-dlp, без группировки по статусу или дате обнаружения. Полная проверка обновляет порядок всего текущего набора, а исчезнувшие из источника исторические записи оставляет в конце. Быстрая проверка ставит проверенное окно впереди и сохраняет прежний порядок остальной части. Для ранее сохранённых подписок один раз включи **«Полная проверка»**, чтобы обновить весь порядок; удалять подписки и терять их состояния не нужно.

Однократное уведомление о материале из другой подписки появляется только при наличии подтверждённого успеха этого точного URL в другой подписке. Постоянная история также подтверждает успех; если связь с другой подпиской неизвестна, материал помечается обработанным без такого уведомления. Постановка в очередь, исходный набор и пропуск не вызывают такое уведомление. Оно не повторяется при каждой проверке или открытии окна.

### Полнота проверки и сохранение данных

Первая проверка всегда полностью перечисляет коллекцию через `yt-dlp`. Затем обычная ручная проверка может ограничиться **20 новыми публикациями**, если исходный набор уже сохранён и источник поддерживает порядок от новых к старым: вкладки YouTube `/videos`, `/shorts`, `/streams` без дополнительных query/fragment либо распознанный раздел самых новых публикаций Pornhub. Корневая страница YouTube-канала, произвольный плейлист и другие источники проверяются полностью.

Окно сравнивается по точным URL со всеми известными материалами подписки, независимо от их состояния. Все URL известны — новинок нет; есть новые и хотя бы один известный — сохранить новые, сохранив прежние записи и их состояния. Нет ни одного известного URL, не подтверждён порядок или ответ непригоден — автоматически перейти к полному обходу. Окно не устанавливает первый исходный набор и не выдаётся за полный архив.

Размер окна **20 не ограничивает число обнаруженных новинок**. Например, при 100 известных и 100 новых роликах окно не найдёт знакомого URL; полный обход вернёт 200 материалов и отметит все 100 новых. Решения по прежним обработанным и пропущенным материалам сохранятся. После проверки все новинки можно принять одним общим подтверждением, а скачивание начать через **«Скачать всю очередь»**.

Запрос окна ограничен 30 секундами для YouTube и 45 секундами для Pornhub внутри общего времени проверки; по его таймауту приложение пробует полный обход. Отмена пользователем останавливает проверку целиком.

Для сверки старой части коллекции включи **«Полная проверка»**. Последние 20 публикаций не обнаруживают произвольные вставки глубже в архиве. Колонка **«Последняя проверка»** показывает время успешной проверки в любом режиме.

RSS/Atom дополняет названия только для точных URL, подтверждённых текущим результатом `yt-dlp`. Ссылки, найденные лишь в ленте, не добавляются во входящие. Неизменившаяся RSS не заменяет проверку коллекции. При недоступности или ошибке ленты результат `yt-dlp` можно сохранить с отдельным предупреждением.

Полная проверка раскрывает вложенные коллекции до отдельных материалов через `yt-dlp --no-flat-playlist`, без скачивания файлов. Это требует запросов метаданных каждого материала и может занимать больше времени, чем быстрый список плейлиста. Она ограничена 10 000 материалов, 180 секундами и 32 МиБ вывода метаданных `yt-dlp`. Для публикаций Pornhub действует отдельный сборщик, описанный ниже. RSS/Atom ограничена 2 МиБ и 12 секундами. Если коллекция превышает предел, ответ обрезан, содержит нераскрытые вложенные источники или непригодные элементы либо полное перечисление не удалось, проверка завершается ошибкой. Она не заменяет исходный набор, список материалов и время последней успешной проверки частичным результатом.

Подписки сохраняются в `%LOCALAPPDATA%\VideoDownloader\subscriptions.json`, отдельно от `session.json` и `successful-downloads.jsonl`. Ранее сохранённые подписки без краткого имени продолжают читаться; имя определяется при успешной проверке или задаётся вручную. Если JSON повреждён, приложение сообщает об ошибке и оставляет файл без изменений. Перед ручным редактированием закрой приложение и сделай копию файла.

### Проверки по интервалу

После первой успешной ручной проверки выбери подписку, включи **«Проверять по расписанию»**, задай число в поле **«Каждые … минут»** и нажми **«Сохранить расписание»**. По умолчанию флажок выключен, интервал — 30 минут; допустимо 5–10080 минут. Для нового источника сначала требуется обычная первая проверка с выбором исходного набора. Настройки старых подписок читаются с выключенным расписанием.

Проверки идут, пока приложение открыто или скрыто в трее. Окно «Подписки» можно закрыть. После полного выхода они прекращаются: Планировщик Windows и служба не создаются. Запуск приложения, включение/возобновление расписания и завершение обслуживания сначала отсчитывают полный интервал; отдельной проверки при запуске нет. После сна выполняется один пропущенный проход, затем новый интервал, без повторения всех пропусков. Источники проверяются последовательно; один сайт — не чаще раза в минуту. При ошибках интервал источника увеличивается до недели, пауза сайта — до часа. Ручная проверка и расписание одновременно не выполняются.

Колонки показывают последнюю попытку, успешную проверку, интервал, следующую проверку и ошибку. Состояние расписания видно также под фильтрами основной очереди. Время следующей попытки приблизительное: ручная проверка, другой источник того же сайта, обновление, обслуживание или выход могут её отложить. Кнопка **«Отменить проверку»** останавливает текущий scan; **«Приостановить»** исключает источник из общей проверки и расписания.

Новые материалы сохраняются во «Входящих» и дают уведомление трея без открытия окна и перехвата фокуса. Прежние непринятые новинки повторного уведомления не вызывают; сообщения нескольких проверок объединяются, уведомление показывается не чаще раза в минуту. Автоматическая проверка получает URL/названия, а обложки загружаются при обычном просмотре; архивная предзагрузка изображений относится к ручной проверке. Нажми **В очередь; запуск кнопкой «Скачать всю очередь»**, затем **«Скачать всю очередь»** самостоятельно: расписание ничего не ставит в очередь и не скачивает. Оно не доказывает доступность каждого материала; подробности недоступного источника остаются в ошибке последней попытки, прежний успешный снимок сохраняется.

Обновление компонентов приостанавливает расписание и дожидается отмены автоматического scan. Установка приложения ждёт завершения проверок. При восстановлении профиля импортированное расписание выключается; включи его заново после проверки источников и cookies. Планировщик Windows, проверка при запуске, фильтры и собственные профили подписок остаются в [дорожной карте](../project/ROADMAP.md).

### Публикации Pornhub

В **«Подписках»** поддерживаются адреса `/channels/имя`, `/model/имя`, `/pornstar/имя` и `/users/имя`, включая локализованные домены и ссылки на вкладку видео. Каналы проверяются по `/videos`, остальные профили — по `/videos/upload`. Начальная страница из параметра `page` игнорируется: обход начинается с первой страницы публикаций. История просмотров, избранное и рекомендации исключаются.

Чтобы скачать архив, при добавлении выбери добавление существующих материалов в очередь, дождись успешной проверки и нажми **«Скачать всю очередь»** в основном окне. Без этого выбора первая проверка запомнит текущие публикации и покажет их как **«Исходный снимок»**, без автоматического добавления в очередь. Для доступа с авторизацией укажи файл cookies в основном окне до проверки; тот же файл используется при скачивании роликов.

При полном обходе обработчик последовательно обходит страницы и повторно проверяет первую страницу. Повторная быстрая проверка запрашивает сортировку новых публикаций, принимает только подтверждённый раздел самых новых видео и сверяет до 20 ссылок. Если сайт не подтверждает этот порядок или в окне нет знакомых URL, используется полный обход. Пределы — 10 000 уникальных роликов, 500 страниц, 15 минут и 32 МиБ итоговых метаданных. Пропуск страницы, повтор списка, изменение первой страницы, неподтверждённая пустая выдача или ошибка доступа завершают проверку без изменения прежнего набора. Если сайт меняет разметку, проверка может потребовать обновления приложения.

Если сайт перенаправляет `/videos/upload` на `/videos` того же профиля, сборщик продолжает обход по конечному адресу. Смена языка домена в пределах того же сайта также допустима. Переход на главную страницу профиля, другой профиль, избранное или страницу входа отклоняется; сообщение показывает конечный адрес без данных авторизации и произвольных параметров запроса.

Если список не распознан, ошибка показывает адрес страницы, названия найденных секций и число карточек вне списка. Для распознанной страницы подтверждения возраста выводится отдельное сообщение. Подтверждение в браузере и запрос загрузчика — разные сессии. Поле **Cookies** в основном окне принимает путь к файлу cookies, экспортированному из браузера после подтверждения возраста или входа; открытие страницы в браузере само по себе не передаёт эту сессию приложению. Без подтверждённого списка прежние результаты сохраняются.

Сборщик создаёт обычные ссылки `https://www.pornhub.com/view_video.php?viewkey=…` (либо соответствующий основной домен сайта) и проверяет манифест полноты. При обнаружении не запрашиваются полные метаданные каждого ролика, поэтому недоступный ролик с известной ссылкой остаётся отдельной задачей и получает собственную ошибку при загрузке. Остальные задачи продолжаются; **«Повторить ошибки»** повторяет неудачные загрузки. История успехов, отмена и восстановление работают для каждого видео отдельно. Сам канал не записывается как успешно скачанный материал.

Папка `collection-plugins/` должна оставаться рядом с приложением. Встроенный `yt-dlp.exe` загружает обработчик только при проверке подписки; установка Python пользователю не требуется. Добавление URL канала обычной кнопкой **«Добавить»** не включает этот сборщик — для импорта по роликам используй **«Подписки»**.

## Таблица загрузок

В таблице **«Загрузки»** находятся результаты и активные задачи. Для выбранного файла доступны `Открыть файл`, `Показать в папке`, `Копировать путь`, `Открыть ссылку`, `Скачать повторно`, `Исходная диагностика`.

Кнопка **«Диагностика…»** в **«Очередь»** и **«Загрузки»**, а также одноимённое контекстное меню открывают события выбранной ссылки, доступные попытки, параметры и причину ошибки. Поиск и фильтры действуют внутри этого задания. **«Копировать видимые события»** учитывает фильтры; **«Сохранить всю диагностику в ZIP…»** сохраняет весь полученный снимок с версиями компонентов. [Ограничения истории и состав пакета](windows-logging.md#диагностика-одного-задания).

Состояния выделены цветом: ожидание — серым, активная загрузка — голубым, успешная — зелёным, прерванная — жёлтым, ошибка — красным.

Шкала задачи учитывает выбранные видео- и аудиокомпоненты: при двух потоках окончание первого даёт 49,5%, обоих — 99%. В состоянии строки отдельно видны текущий компонент и его процент, затем объединение, обработка и сохранение. 100% означает успешную публикацию результата. Компоненты имеют равные веса, поэтому шкала не является точной оценкой байтов или оставшегося времени. Повторная попытка обозначается явно и может сбросить прогресс. При прямом URL плейлиста с неизвестным числом роликов шкала относится к текущему ролику; [подробности и ограничения](windows-logging.md#как-читать-проценты-и-этапы).

## Журнал и профили трассировки

Над журналом в панели **«Загрузки»** находится выбор подробности: **«Только ошибки»**, **«Обычный»**, **«Прогресс загрузок»** и **«Подробный yt-dlp»**. Профиль применяется к новым событиям сразу, сохраняется между запусками и независим от **«Профиль»** скачивания.

Для скачков процентов включи **«Прогресс загрузок»**: записи связываются с сессией, точным URL через короткий `job` и работником `T1`–`T4`. Видны смена компонента, сброс счётчика, повтор и расчёт общей шкалы. **«Подробный yt-dlp»** добавляет вывод stdout/stderr. Сырой процент компонента в трассе может отличаться от общей шкалы задачи; при прямом URL плейлиста текущий ролик тоже меняется.

В записях отдельного задания есть `video_seq` с номером строки очереди и `video` с названием либо URL; эти подписи также входят в участников общей шкалы. Префикс `[yyyy-MM-dd HH:mm:ss.fff]` показывает локальное время компьютера с миллисекундами. Прежний `#`-номер записи не выводится и не являлся кодом цвета; журнал отображается обычным текстом.

Кнопки **«Копировать журнал»** и **«Сохранить журнал…»** выгружают сохранённый в памяти хвост — до 5 000 записей и 2 МиБ. Экран показывает до 2 000 строк и 512 КиБ. **«Очистить»** очищает экран и память; автоматические файлы в `%LOCALAPPDATA%\VideoDownloader\logs` сохраняются, а самые старые заменяются по мере заполнения. Подробности и сценарий для четырёх параллельных загрузок — в [руководстве по журналу](windows-logging.md).

Публичные идентификаторы видео и плейлиста в URL, например `v`, `list` и `viewkey`, остаются видимыми. Неизвестные параметры, данные входа и токены маскируются. Объяснение ошибки и исходная диагностика разделяются настоящими переносами строк; продолжения сообщения имеют отступ.

## Параллельность, пауза и остановка

**«Параллельные загрузки»** задаёт максимальное число одновременно скачиваемых URL; **«Фрагменты»** — число параллельных фрагментов внутри `yt-dlp`. `Ограничение скорости` ограничивает скорость.

**«Пауза / Продолжить»** приостанавливают и возобновляют процессы Windows, включая связанные задачи FFmpeg. **«Остановить»** отменяет сессию и выполняет очистку временных файлов, прежде чем окончательно закрыть программу. После остановки оставшиеся URL можно запустить вновь.

Таймер сессии начинается при нажатии **«Скачать всю очередь»**, включает время паузы и останавливается после завершения всех заданий и очистки. Новый запуск скачивания или явный повтор начинает отсчёт заново. Получение метаданных и ожидание в очереди до запуска скачивания таймер не запускают.

При нажатии X приложение предлагает спрятать окно в трей, выйти или остаться. При работе в трее загрузки и получение превью продолжаются.

## Настройки видео и аудио

| Поле | Доступные варианты и особенности |
| --- | --- |
| `Качество` | `Лучшее`, 2160, 1440, 1080, 720; возможно снижение разрешения при отсутствии формата |
| `Кодек` | `Авто`, `H264`, `VP9`, `AV1`; предпочтение, а не жёсткий запрет альтернатив |
| `Контейнер` | `Авто`, `MP4`, `MKV`, `WebM`; для объединения потоков может понадобиться FFmpeg |
| `Аудиодорожка` | По умолчанию, оригинальная или выбор по языкам |
| `Языки аудио` | Коды через запятую, например `ru`, `en`, `pt-BR` или `ru,en`; поле доступно в режиме «По языкам» |
| `Ограничение скорости` | Максимальная скорость, передаётся в `yt-dlp --limit-rate` |
| `Субтитры` | Обычные и автоматически распознанные субтитры, языки (например, `ru.*,en.*`), встраивание |
| `Метаданные` | Обложка, главы, описательная информация |
| `Архив по дате` | Подкаталог с датой загрузки |
| `Только MP3` | Сохранение только аудио |
| `Шаблон имени файла` | Шаблон названия для `yt-dlp`, например `%(title)s [%(id)s].%(ext)s` |

Шаблон имени допускает относительные подпапки; абсолютные пути и компоненты `..` отклоняются до запуска `yt-dlp`. Внешние конфигурации `yt-dlp` игнорируются. Перед успешным завершением приложение проверяет наличие и пригодность итогового медиафайла. Ответ загрузчика без файла считается ошибкой и не попадает в историю.

Наведи указатель на **«Шаблон имени файла»**, чтобы прочитать краткую подсказку. Кнопка **«Справка…»** рядом открывает отдельное окно с синтаксисом `%(поле)s`, распространёнными полями, примерами и ограничениями. Например, `%(title)s [%(id)s].%(ext)s` подставляет название, уникальный ID и фактическое расширение; его не нужно заменять жёстко заданным `.mp4`.

Сетевые сбои повторяются с паузой, обычно по последовательности 5, 10, 20 секунд; ошибки доступа или недоступного материала не должны повторяться бесконечно.

### Выбор аудиодорожки

В правой панели выбери **«Аудиодорожка»** перед запуском скачивания:

- **«По умолчанию»** сохраняет обычный автоматический выбор yt-dlp. Этот режим используется и для настроек прежних версий.
- **«Оригинальная»** выбирает дорожку, которую источник через yt-dlp явно пометил как `original`. Если отметки нет, программа не угадывает язык оригинала и завершает задание ошибкой недоступного формата.
- **«По языкам»** использует поле **«Языки аудио»**. Например, `ru` выбирает лучший доступный русский звук, включая региональные варианты вроде `ru-RU`; `pt-BR` требует именно этот вариант. Регистр кодов не важен. Можно указать до восьми кодов; повторы одного кода объединяются.

Для одного языка работает обычное видео или **«Только MP3»**. Для нескольких, например `ru,en`, отключи MP3 и выбери **Контейнер → Авто** либо **MKV**: результатом будет MKV с одной лучшей дорожкой для каждого языка в указанном порядке. Такой режим требует отдельных видео- и аудиопотоков у источника. MP4 и WebM для нескольких дорожек отклоняются до запуска; настройка контейнера не меняется автоматически.

Если выбранного языка, отметки оригинала или хотя бы одной из нескольких запрошенных дорожек нет, задание завершается ошибкой. При снижении качества и смене предпочтительного кодека сохраняется тот же выбор звука. Источник без сведений о языках можно скачать в режиме **«По умолчанию»**. Переключение профиля не сбрасывает выбор дорожек; после выбора профиля MP3 оставь один язык.

Настройка действует на задания следующей сессии; уже работающая сессия сохраняет прежние параметры. Выбор сохраняется в настройках приложения и не переносится в `.vdqueue`, где остаются только URL и названия.

## Свободное место на диске

Под **«Папка загрузок»** отображается свободное место на локальных дисках, используемых очередью. Проверка выполняется в фоне и не создаёт папку назначения. Датированная архивная папка и папка подписки учитываются по фактическому пути. Отдельно проверяется диск временных файлов Windows, где загрузчик хранит входные потоки и результат обработки перед публикацией.

Размер можно оценить, когда выбранные форматы сообщают `filesize` или `filesize_approx`. Видео и отдельное аудио складываются; для фрагментов с известной длительностью исходника суммируются доли выбранного времени. Если длительность неизвестна, запас считается как полный известный размер потоков для каждого фрагмента. Это приблизительная оценка: контейнер, перекодирование и обработка могут изменить размер. Для временного диска резервируется примерно два входных размера, для диска результата — ещё один; на общем диске суммы объединяются. Неизвестные размеры явно посчитаны отдельно и не входят в известную часть. В автоматическом режиме размер часто остаётся неизвестным.

Перед запуском скачивания окно **«Проверьте свободное место»** появляется, если показанный резерв больше доступного места, либо размер неизвестен и осталось менее 1 ГиБ. **«Отмена»** не начинает попытку и сохраняет её прежние пути и владение. **«Продолжить»** разрешает запуск с этой оценкой. Если во время проверки или открытого окна поменять очередь, параметры или папку, запуск откладывается: нажми **«Скачать всю очередь»** заново. Сведения о месте не являются проверкой всех прав записи и не гарантируют успешное завершение.

Во время сессии диски проверяются не чаще одного раза в пять секунд. При остатке менее 1 ГиБ появляется предупреждение в окне, журнале и трее. Оно повторяется только после восстановления достаточного запаса и нового снижения либо в новой сессии. Само предупреждение не останавливает и не перезапускает задания: используй **Пауза** или **«Остановить»**, если требуется освободить место. Приложение ничего не удаляет ради места.

Для UNC-папок и сетевых дисков ёмкость автоматически не запрашивается. Недоступный диск, отказ в доступе и таймаут показываются как неизвестное или недоступное место, а не как нулевой остаток.

## Формат и фрагмент отдельного видео

Выбери одну строку **«Очередь»** и нажми **«Формат и фрагмент…»** под превью. Окно относится к её точному URL и не запускает задание в очереди. Сведения поступают от общего фонового превью; дождись метаданных, прежде чем задавать точные форматы или фрагмент. Для прямой ссылки на коллекцию добавь отдельные материалы через подписку: параметры не применяются к первому ролику плейлиста автоматически.

Таблица показывает фактические форматы, сообщённые источником: ID, тип, разрешение, частота кадров, HDR, кодеки, язык и размер. **«Неизвестно»** означает отсутствие сведений, **≈** — приблизительный размер. Размер относится к полному потоку; размер готового фрагмента или объединённого файла может отличаться. Если источник вернул больше 1024 пригодных форматов, показываются последние 1024 и сообщение о скрытой ранней части списка.

В режиме **«Автоматически по общим настройкам»** действуют общие настройки «Качество», «Кодек» и выбор аудиодорожки. В режиме **«Выбрать точные форматы»** выбери основной формат. Для видео без звука обязательно выбери отдельный аудиоформат; к видео со звуком вторую дорожку добавить нельзя. Можно выбрать только аудио, а для **«Только MP3»** основной формат должен быть аудио без видео. Оставь **«Аудиодорожка → По умолчанию»**: точные форматы уже определяют звук.

Точные ID имеют приоритет над настройками «Качество» и «Кодек». Если выбранный формат исчезнет, задание завершится ошибкой без автоматической замены другим качеством. Несовместимые с MP4 или WebM кодеки отклоняются; выбери подходящие потоки либо **Контейнер → Авто/MKV**. Перекодирования для исправления такой несовместимости нет.

Поля **«Начало»** и **«Конец»** задают фрагмент. Допустимы секунды, `М:СС` или `ЧЧ:ММ:СС`, например `75.250` или `00:01:15.250`; дробная часть через точку содержит до трёх цифр. Начало неотрицательное, конец больше начала и не выходит за известную длительность. Оставь оба поля пустыми для полного материала; только одно пустое поле считается ошибкой. Для обработки фрагмента используется FFmpeg.

При известной длительности шкала показывает выделенный диапазон и его длительность. Перетаскивай ручки **«Н»** и **«К»** либо нажми на шкалу возле нужной границы: существующие поля времени и карточки кадров синхронизируются. **«К началу»** и **«К концу»** переводят фокус на соответствующую границу и делают её время доступным в карточке. Поля полного материала остаются пустыми до явного действия со шкалой.

На ручке доступны **←/→** для одного шага, **Shift + ←/→** или **Page Down/Page Up** для десяти шагов, **Home/End** для допустимого края. Кнопки **«− кадр»** и **«+ кадр»** уточняют отдельные границы. При выбранном точном видеоформате используется его частота кадров; в автоматическом режиме покадровый шаг доступен, когда все известные видеоформаты имеют одинаковую частоту кадров. Дробная частота кадров привязывает шаг к сетке кадров без накопления округления. Поля отображают миллисекунды, поэтому подпись времени кадра приблизительная. Если частота кадров неизвестна или различается, кнопки и пояснение показывают шаг **0.1 с**. Границы не пересекаются; последняя точка шкалы не выходит за длительность после округления.

При неизвестной длительности шкала выключена: задай допустимые границы полями, после чего кнопки пошаговой настройки остаются доступны. Некорректный ввод не исправляется автоматически; при известной длительности его можно заменить новым диапазоном перетаскиванием. Текущая активная строка или защищённый checkpoint блокируют и поля, и шкалу. Скачивание по-прежнему начинается отдельно через **«Скачать всю очередь»**.

Под полями находятся **«Кадр начала»** и **«Кадр перед концом»**. После короткой паузы во вводе приложение получает реальные кадры; подпись **«Кадр около…»** показывает время предпросмотра. Для конца берётся момент немного раньше указанной границы, в том числе когда конец совпадает с длительностью видео. Кнопка **«Обновить кадры»** повторяет запрос. Изменение времени отменяет прежний запрос этого поля, поэтому запоздалый кадр не заменяет актуальный.

Для кадров нужен установленный FFmpeg. Поддерживаются прямые HTTP(S)-видеопотоки MP4/MOV/M4V/WebM/MKV, завершённые HLS-плейлисты (включая TS, fMP4 и обычный AES-128 для TS) и статический DASH. Для HLS/DASH приложение получает только несколько сегментов около выбранного времени, включая нужный init-сегмент. Live-трансляции, DRM, аудио без видео и коллекции не поддерживаются; зашифрованный HLS fMP4 пока тоже недоступен. Ограничение времени, объёма или неподдержанная схема манифеста могут оставить кадр недоступным. В автоматическом режиме предпросмотр может использовать поток меньшего качества: размер картинки не показывает качество итогового видео.

Пустое или некорректное время очищает соответствующую картинку и показывает пояснение. Время за пределами известной длительности тоже не даёт кадра. **«Применить»** проверяет допустимость диапазона и форматов независимо от готовности кадров. Ввод времени и обновление кадров не запускают задание в очереди и не пополняют историю.

**«Применить»** сохраняет параметры строки, **«Сбросить параметры строки»** возвращает полный материал и автоматический формат, **«Закрыть»** оставляет прежний выбор. Под кнопкой основного окна видны **«Следующая попытка»** и, для готового результата, **«Сохранённый результат»**. Изменение параметров готовой строки сохраняет её файл и историю; обычный запуск не скачивает завершённые задания заново. Для новой попытки используй **Скачать повторно** или **Скачать выбранные строки**.

Параметры фиксируются при запуске скачивания. Строки текущей сессии, выполняемые или ожидающие очистки строки недоступны для изменения. Выбор сохраняется после перезапуска и при временных повторах; старые сессии без этих полей означают полный материал и автоматический формат. В `.vdqueue` эти параметры не входят.

Успешный фрагмент получает готовый файл и состояние «Готово». Он не записывает URL как полностью скачанный в постоянную историю и не помечает материал подписки обработанным.

### Посмотреть и послушать фрагмент

В окне **«Формат и фрагмент…»** после ввода обеих границ нажми **«Начало фрагмента»** или **«Конец фрагмента»**. Предпросмотр играет до 15 секунд с соответствующей стороны выбранного диапазона; подпись **«Предпросмотр»** показывает фактическое начало и конец, а **«Позиция источника»** — текущее время материала. Например, для диапазона `00:00:10 — 00:01:40` начало покажет `00:00:10 — 00:00:25`, конец — `00:01:25 — 00:01:40`.

**«Пауза» / «Продолжить»**, **«Стоп»** и полоса поиска управляют только подготовленным отрывком. Звук берётся из выбранного основного или отдельного аудиоформата. При автоматическом выборе действует настройка аудиодорожки; если выбрано несколько языков, предпросмотр играет первый язык. Источник без звука подписывается явно. Режим MP3 позволяет послушать аудио без изображения.

Поддерживаются прямые потоки, завершённый HLS и статический DASH с доступными дорожками. Для подготовки нужны FFmpeg и FFprobe из раздела зависимостей; воспроизведение зависит от поддержки H.264/AAC и аудиоустройства Windows. Live, DRM, разрыв временной шкалы и источники, превышающие лимиты, могут дать пояснение об отсутствии предпросмотра. Допустимый выбор можно **«Применить»** во время ожидания и после ошибки воспроизведения.

Изменение времени или формата отменяет прежнюю подготовку и останавливает плеер. Закрытие окна освобождает его временный файл. Одновременно допускаются до четырёх подготовленных отрывков; кеш ограничен 64 МиБ, каждый отрывок — 16 МиБ. Загрузка медиа для одного предпросмотра ограничена 64 МиБ и одной минутой с учётом ожидания метаданных. Предпросмотр не запускает очередь, не записывает историю и не изменяет готовые скачанные файлы.

### Звуковая волна у границ

После ввода обеих границ нажми **«Волна начала»** или **«Волна конца»**. Кнопка прокрутит окно к своей области звука. Программа подготовит короткий участок и измерит реальный звук выбранной дорожки: внешние столбики показывают пики, внутренние — среднюю громкость. Это помогает заметить речь и паузы. Шкала и подпись **«Участок источника»** показывают исходное время материала, цветная метка — редактируемую границу. Волна доступна и в режиме MP3 без видео; при нескольких языках измеряется первый выбранный язык, как в проигрываемом предпросмотре.

При известной длительности участок охватывает до 15 секунд около границы и ограничивается началом и концом материала. Например, возле `00:00:20` это `00:00:12.500 — 00:00:27.500`. При неизвестной длительности волна конца показывает до 15 секунд перед концом, а волна начала не запрашивает время дальше указанного конца фрагмента. Подпись всегда показывает фактическое окно. Если звук заканчивается раньше окна, приложение указывает его окончание и сохраняет оставшийся промежуток на шкале.

Щелчок по волне или перетаскивание метки меняет только соответствующее поле **«Начало»** либо **«Конец»**. Стрелки меняют время на **0.1 с**, Shift со стрелками — на **1 с**, Home/End переходят к допустимым краям показанного окна. Границы сохраняют порядок; метку нельзя перетащить за вторую границу. Во время такой настройки измеренное окно остаётся на месте. Чтобы получить звук около новой границы, снова нажми кнопку волны. Параметры строки сохраняет только **«Применить»**; **«Закрыть»** оставляет прежний выбор.

Волна загружается только по кнопке; **«Отменить волну»** очищает свою карточку и отменяет её подготовку. Обычная правка времени, смена формата, аудиодорожки или строки списка фрагментов очищает прежние волны. **«Стоп»** проигрывателя, запрет редактирования и закрытие окна также отменяют запросы. Поздний ответ не возвращает прежнюю волну. Допустимый диапазон можно применить во время подготовки или после ошибки.

Нужны FFmpeg/FFprobe и источник, доступный короткому предпросмотру. Отсутствие аудиодорожки и измеренная тишина объясняются отдельно; ошибка декодирования не подменяется выдуманной волной. Волна использует общий ограниченный кеш коротких клипов: до четырёх отрывков, 64 МиБ суммарно и 16 МиБ на файл. Один запрос получает до 64 МиБ медиа, выполняется не более минуты с ожиданием метаданных и не скачивает весь ролик. Очередь, история и готовые файлы не меняются.

### Несколько фрагментов одного видео

Включи **«Несколько фрагментов»** в том же окне. Поля **«Начало»** и **«Конец»**, кадры, звуковые волны и проигрываемый предпросмотр относятся к выбранной строке списка. Смена строки останавливает предыдущий предпросмотр и очищает волны. **«Добавить фрагмент»** создаёт пустой диапазон, **«Удалить фрагмент»** убирает выбранный. **«Выше»** и **«Ниже»** задают порядок получения файлов. Правки времени сразу сохраняются в черновике выбранной строки; отдельной кнопки сохранения диапазона нет. Окончательно параметры применяет **«Применить»**.

Можно выбрать до 32 диапазонов. Каждый должен иметь начало и конец; повторы и пересечения запрещены, соседние интервалы разрешены. Диапазоны могут идти в любом порядке. Выключение списка оставляет только текущий диапазон; пустые поля в одиночном режиме возвращают полный материал. Закрытие окна сохраняет прежние параметры задания.

По умолчанию одна строка очереди создаёт отдельные файлы для всех диапазонов. К пользовательскому шаблону имени добавляется префикс `fragment-<начало>-<конец>ms`: числа обозначают границы в миллисекундах. Это различает даже короткие соседние отрывки; уже существующие файлы не перезаписываются. Двойной щелчок готовой строки открывает первый фрагмент из списка, остальные доступны в папке результата.

Успех подтверждается только после получения и общей публикации всех выбранных файлов. Ошибка или отмена неполного набора не публикует отдельный успех первого отрывка; временные файлы принадлежат только этой попытке. Общий прогресс учитывает все фрагменты. Список сохраняется после перезапуска, фиксируется при запуске скачивания и не переносится в `.vdqueue`. Полная история URL и обработанное состояние подписки остаются без изменений даже после успеха всех отрывков.

### Субтитры отдельных фрагментов

Для одного диапазона и нескольких отдельных файлов субтитры обрезаются по границам каждого диапазона и отсчитываются от его начала. Например, реплика `5.5–6.5 с` исходника в отрывке `5–7 с` получит время `0.5–1.5 с`. Пересекающие границу реплики сохраняют только попавшую внутрь часть; реплики снаружи исключаются. Выбор языков и автоматических субтитров действует как обычно.

Поддерживаются исходные WebVTT, SRT, ASS и SSA. Отдельные файлы сохраняются как `.vtt`, в том числе при включённом встраивании. Оформление и позиционирование могут упрощаться при преобразовании; одновременные реплики при встраивании объединяются без потери текста. Встраивание поддерживает MP4/MOV/M4A, MKV/MKA и WebM. Если у выбранного языка нет реплик внутри диапазона, остаётся пустой `.vtt`, а пустая встроенная дорожка не создаётся. Отсутствующий на сайте язык не подменяется другим.

Прочие форматы, включая TTML и JSON3, завершают попытку ошибкой до публикации файлов. Удаление SponsorBlock дополнительно меняет временную шкалу: для фрагмента выключи **SponsorBlock** либо субтитры. Ошибка преобразования или отмена сохраняет прежние готовые файлы и не добавляет полный URL в историю. Субтитры полного видео обрабатываются обычным способом.

### Объединить фрагменты в один файл

После добавления не менее двух диапазонов включи **«Объединить выбранные фрагменты в один файл»** и нажми **«Применить»**. Кнопка **«Скачать всю очередь»** запускает получение всех выбранных отрезков и их соединение в порядке списка; сортировки по времени нет. Кадры, шкала и плеер по-прежнему показывают выбранный диапазон, а не будущую склейку. Получится один файл с префиксом `merged-<число>-fragments`; существующие файлы сохраняются с отдельным именем.

До скачивания совместимость ещё неизвестна. После получения всех отрезков FFprobe проверяет реальные контейнеры, параметры, кодеки, временные базы и все аудиодорожки. Совместимые потоки соединяются без дополнительного перекодирования. Это относится к этапу склейки: само точное вырезание диапазонов через yt-dlp может использовать перекодирование для границ.

При несовместимых параметрах задание завершается ошибкой, пока ты явно не включишь **«Разрешить дополнительное перекодирование при несовместимости потоков»**. Этот выбор может изменить кодеки и качество. Для MP4/MOV/MKV применяется H.264/AAC, для WebM — VP9/Opus; размер и частота кадров приводятся к первому отрезку, при необходимости добавляются поля. Все исходные аудиодорожки сохраняются в прежнем порядке с языками; различное число дорожек, языки или раскладки каналов приводят к отказу, а не удалению звука. HDR, высокая битность, альфа-канал, неквадратные пиксели, неизвестная частота кадров или частота выше 240 кадр/с и неподдержанные пиксельные форматы не допускают такой нормализации; выбери совместимые потоки или отдельные файлы.

Для склейки выключи **«Скачать субтитры»**, **«Включить автоматические субтитры»** и **«Встроить субтитры в медиафайл»**: перенос и сдвиг субтитров пока не поддерживаются. Встроенная обложка первого отрезка сохраняется в MP3/MP4/MOV/FLAC. Для остальных контейнеров склейка со встроенной обложкой пока отклоняется: выключи **«Встроить обложку»** либо сохрани отдельные файлы. При включённых главах локальные главы сдвигаются к общей временной шкале; для отрезка без глав создаётся глава «Фрагмент N». Прочие отдельные sidecar-файлы отрезков в результат склейки не входят.

Готовность подтверждается проверкой единственного медиафайла, его контейнера, длительности и дорожек, затем общей публикацией. Ошибка или отмена до публикации убирает только временные файлы этой попытки. Ранее готовый результат сохраняется при редактировании и **Скачать повторно**; новая попытка владеет только новым файлом. Склейка остаётся частичным результатом и не отмечает весь URL скачанным или материал подписки обработанным.

Оценка временного места учитывает две копии для обычной склейки и три при разрешённой нормализации: исходные отрезки, нормализованные отрезки и готовый файл. Это приблизительный резерв: перекодированный размер заранее неизвестен. Подробности этапов доступны в [журнале Windows](windows-logging.md).

## Системный трей

При наведении курсора значок показывает компактную статистику:

~~~text
VD | Готово 12 Осталось 5 Ошибок 2 | 2.5 МБ/с
~~~

Поля расположены в порядке **Готово → Осталось → Ошибок**. Во время паузы показывается «Пауза», после завершения — «Завершено». Сообщение ограничено длиной, поддерживаемой Windows `NotifyIcon`. Двойной щелчок или «Открыть» возвращает окно; «Выход» закрывает приложение. В трее также есть «Открыть папку загрузок».

## Зависимости и интеграция с браузером

В разделе **«Компоненты»** доступны проверка компонентов, обновление `yt-dlp`, установка FFmpeg и регистрация протокола `videodownloader://` в `HKCU\Software\Classes\videodownloader`. После регистрации внешний вызов может добавить ссылку в работающий экземпляр приложения.

Установка FFmpeg скачивает внешний архив; для этого нужны сеть и права записи в папку программы. Проверка цифровой подписи скачиваемого архива отдельно пока не реализована.

## История и восстановление после перезапуска

История успешных URL хранится в `successful-downloads.jsonl`. Перед повторной загрузкой известного URL появляется диалог: загрузить снова, пропустить, применить выбор ко всем совпадениям либо отменить начало сессии. Данные не удаляются при очистке очереди.

Кнопка **«История…»** рядом с **«Загрузки»** открывает отдельное окно. Поиск принимает название, URL, источник или местную дату `ГГГГ-ММ-ДД`; он просматривает весь файл истории, а не только текущую страницу. Если совпадений много, показываются последние записи с явным счётчиком. Повторные успешные попытки одного URL остаются отдельными событиями. Старые события без даты, названия или путей читаются без выдуманных значений.

В новых событиях после подтверждённой публикации полного материала сохраняются название, имя подписки либо сайт и пути медиафайлов. Для большой коллекции список путей может быть сокращён — окно сообщает об этом. Фрагменты по-прежнему не пополняют историю полного URL. Сохранённый путь помогает найти файл и не служит доказательством права удаления.

Выбери запись и нажми **«Проверить файлы записи»**. Проверка идёт в фоне; **«Отменить проверку»** прекращает ожидание. Результаты различают **«Файл доступен»**, **«Файл не найден»**, отказ или таймаут доступа, а также небезопасный/неподдерживаемый путь. Отключённый диск или отказ в доступе не превращаются в доказанное отсутствие. **«Открыть файл»** и **«Открыть папку»** ещё раз проверяют выбранную цель перед явным открытием; при отсутствующем файле его существующая папка остаётся доступной. Из истории нельзя запускать исполняемые файлы, ярлыки или пути через reparse points. **«Копировать путь»** копирует выбранное значение.

Просмотр, поиск и проверка файлов не изменяют историю или очередь и не запускают скачивание. **«Обновить историю»** перечитывает события, записанные после открытия окна. Повреждённые данные остаются без изменений с сообщением об ошибке; очистки или удаления успехов в этом окне нет.

Очередь и настройки атомарно сохраняются в `session.json`. После запуска можно восстановить незавершённую очередь; скачивание не начинается автоматически. Активные задания прошлого запуска переходят в состояние прерванных. Настройки применяются даже при отказе от восстановления строк. Пока открыт диалог восстановления, автосохранение защищает исходный файл; повреждённый checkpoint остаётся без изменений.

Сохраняется чтение данных прежних версий. Если старый процесс PowerShell ещё работает с этими данными, восстановление и начало новой сессии блокируются: заверши прежнюю загрузку и перезапусти программу. Подробности восстановления — в [архитектуре](../developer/architecture.md).

История поддерживает корректную последнюю JSON-запись без завершающего перевода строки. Повреждённый незавершённый хвост не исправляется молча; при ошибке чтения истории новый запуск блокируется. Форматы данных прежних версий сохраняются; повторная установка не требует их удаления.

## Резервная копия профиля

**«Резервная копия…»** открывает экспорт и восстановление Windows `.vdbackup`. В окне показываются состав, исключённые приватные адреса и изменения перед отдельным подтверждением. Настройки применяются с сохранением локальных папок и cookies; подписки можно объединить или заменить, история всегда объединяется. Очередь, медиафайлы и права на них сохраняются. Загрузки и проверки источников сами не запускаются. [Пошаговая инструкция и границы архива](windows-backup.md).

## Обновление приложения

Раздел **«Обновление приложения»** проверяет стабильный Latest Release официального репозитория при запуске. Результат виден в строке состояния, без отдельного уведомления. При сетевом отказе можно повторить **«Проверить обновление»** вручную; такая проверка показывает причину ошибки. Проверка доступности сама ничего не устанавливает.

**«Обновить и перезапустить»** доступна для более новой версии, когда закончены скачивания, проверки подписок и операции с зависимостями. Также нужно завершить восстановление очереди и незавершённую очистку, устранить ошибку сохранения настроек и закрыть прежний PowerShell-движок, если он ещё работает. Папка приложения должна быть доступна для записи.

Установщик загружает только официальный Windows ZIP и `SHA256SUMS.txt`, проверяет SHA-256, версию и состав пакета. Затем приложение сохраняет checkpoint и полностью завершается. Отдельный временный процесс заменяет только файлы поставки, сохраняет прежние файлы для отката и перезапускает приложение. Пользовательские настройки, очередь, история, cookies, загрузки, отдельно установленные FFmpeg/ffprobe и посторонние файлы сохраняются. Если новый пакет совпадает по пути с посторонним файлом, установка останавливается.

Сохраняй `windows-package.json` рядом с EXE: он определяет файлы установленного комплекта. Для первого перехода с `v2.0.38` и более ранних версий или при отсутствии этого файла распакуй полный новый ZIP вручную по [инструкции установки](windows.md#установка-и-обновление). Обновление приложения из интерфейса относится только к Windows. **«Обновить yt-dlp»** обновляет отдельный загрузчик.

При ошибке замены выполняется откат. Если временный установщик аварийно завершился, следующий запуск приложения сначала восстанавливает прежний комплект из проверенной резервной копии, затем открывает окно. При ошибке восстановления оно останавливается: резервные файлы остаются в `%TEMP%\VideoDownloaderUpdates`, а в папке приложения сохраняется `.video-downloader-update.json` для повторного запуска восстановления. Сохрани оба и резервную копию пользовательских данных; при необходимости восстанови полный комплект из ZIP в отдельной папке. Встроенный установщик предлагает только более новые версии; намеренный переход к прежнему выпуску выполняется вручную.
