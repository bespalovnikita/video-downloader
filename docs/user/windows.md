## Установка и обновление

Нужна **Windows 10/11 x64**. Скачай `VideoDownloader-Windows-x64.zip` из [последнего стабильного релиза](https://github.com/bespalovnikita/video-downloader/releases/latest), распакуй в доступную для записи папку и запусти `VideoDownloader.exe`. Сохрани соседние папки, `yt-dlp.exe` и `windows-package.json`; архив не нужно запускать изнутри ZIP. Установка Python, PowerShell или .NET Runtime для готового ZIP не требуется.

При запуске приложение проверяет последнюю стабильную версию без отдельного всплывающего окна. В разделе **«Обновление приложения»** можно нажать **«Проверить обновление»** вручную. Если доступна новая версия, заверши скачивания, проверки подписок и операции с зависимостями, затем нажми **«Обновить и перезапустить»**. Приложение проверит архив и его SHA-256, сохранит очередь, закроется, заменит собственные файлы и запустится снова. Настройки, очередь, история, cookies, скачанное медиа и отдельно установленные FFmpeg/ffprobe сохраняются. Восстановленная очередь ждёт нажатия «Скачать всю очередь».

**Первый переход с `v2.0.38` и более ранних выпусков выполняется вручную.** Полностью закрой прежний экземпляр, включая значок в трее, сделай [резервную копию данных](troubleshooting.md#windows-backup) и распакуй новый ZIP в отдельную папку. То же требуется, если в установленном комплекте нет `windows-package.json`. Не смешивай файлы разных выпусков. Данные по умолчанию читаются из прежнего `%LOCALAPPDATA%\VideoDownloader`. Если FFmpeg был установлен рядом со старым EXE, в новой папке снова проверь зависимости и при необходимости нажми **«Установить FFmpeg»**.

При ошибке установки восстанавливаются прежние файлы. После аварийного прерывания следующий запуск сначала восстанавливает прежнюю версию и затем открывает окно. Если восстановление не удалось, сохрани указанные резервные файлы и установи полный ZIP в отдельную папку; [порядок восстановления](windows-reference.md#обновление-приложения). Кнопка **«Обновить yt-dlp»** отдельно обновляет загрузчик.

Если хочешь собирать приложение самостоятельно, используй [гайд локальной сборки Windows](../developer/windows-build.md).

## Перед началом

1. Запусти `VideoDownloader.exe` из распакованного комплекта.
2. В разделе **«Компоненты»** проверь зависимости. Если FFmpeg или ffprobe отсутствуют, нажми **«Установить FFmpeg»** и дождись завершения установки. Перед скачиванием приложение проверяет оба инструмента.
3. Выбери **«Профиль»**: например, **«Универсальный»** или **«Совместимый MP4»**. Затем при необходимости измени качество, субтитры и **«Архив по дате»**. Выбор другого профиля заново задаёт связанные настройки, включая архивирование по дате.
4. В **«Папка загрузок»** укажи папку, например `D:\Video`. Это пример: можно выбрать другой доступный каталог кнопкой **…**.
5. Если источник требует авторизации, укажи в **«Файл cookies»** путь к экспортированному файлу cookies в формате Netscape: [отдельная инструкция для Chrome / Edge / Firefox](cookies.md). Открытая вкладка браузера сама по себе не передаёт вход приложению.

Под **«Папка загрузок»** показаны свободное место и оценка известной части очереди. Учитываются диск результата и диск временных файлов Windows. При нехватке места перед запуском скачивания появляется окно **«Проверьте свободное место»**: **«Отмена»** оставляет попытку и очередь до следующего запуска, **«Продолжить»** явно разрешает начать с показанной оценкой. Размеры, которых источник не сообщил, остаются неизвестными. [Как считается запас и работают предупреждения](windows-reference.md#свободное-место-на-диске).

Добавление ссылки, получение названия и проверка подписки не являются скачиванием. Обычная очередь запускается кнопкой **«▶ Скачать всю очередь»**, включая подходящие строки, скрытые фильтром. Исключение — обычные ссылки, добавленные вручную во время работающей загрузки: они могут присоединиться к текущей сессии. Материалы подписок и [перенесённая с другого клиента очередь](queue-transfer.md) всегда ждут следующего нажатия **«Скачать всю очередь»**.

Чтобы найти задание, используй **«Поиск в очереди»**, статус и подписку над списком. Счётчик показывает видимое и общее число строк. **«Сбросить фильтры»** возвращает все строки; поиск меняет только представление. **«Удалить выбранные»** относится к видимому выделению, а **«Очистить всю очередь»** — ко всей очереди. [Область действий и клавиши](windows-reference.md#поиск-и-фильтры).

Запрос названия и обложки начинается с постановки в фоновую очередь сразу после добавления URL или материала подписки, без запуска скачивания и выбора строки. Единственный работник получает их последовательно, с учётом ответа сайта и предыдущих запросов. Название и первая картинка доступны по готовности, до завершения всей галереи. Выбор строки показывает уже полученное превью либо повышает приоритет ещё не готового запроса.

В примерах ниже `VIDEO_ID`, `PLAYLIST_ID`, `CHANNEL` и `CHANNEL_ID` — обозначения, которые нужно заменить своими значениями. Надёжнее копировать настоящий адрес из браузера.

## 1. Скачать одно видео с YouTube

Пример формы адреса:

```text
https://www.youtube.com/watch?v=VIDEO_ID
```

1. Скопируй ссылку на нужный ролик. Если нужен только он, используй адрес без параметра `list`: ссылка на видео, открытое внутри плейлиста, может передать yt-dlp весь плейлист.
2. Вставь URL в поле над **«Очередь»** и нажми **«+ Добавить»**. Для ссылки в буфере можно использовать **«Вставить»**.
3. Дождись фонового получения метаданных. Чтобы видеть названия в таблицах, включи **«Показывать названия видео вместо URL»**. Для запуска скачивания ждать обложку необязательно.
4. Проверь **«Профиль»** и **«Папка загрузок»**, затем нажми **«▶ Скачать всю очередь»**.
5. Если приложение обнаружит эту точную ссылку в истории, выбери повторное скачивание или пропуск. Отмена диалога не запускает загрузку.
6. Дождись успешного завершения. Открой скачанную строку в **«Очередь»** двойным щелчком либо выбери результат в **«Загрузки»** и нажми **Открыть файл** или **Показать в папке**. Кнопка **«📂 Открыть папку загрузок»** открывает настроенный каталог без выбора строки.

**Результат:** файл появится в `D:\Video`, а при включённом **«Архив по дате»** — в `D:\Video\ГГГГ-ММ-ДД`. Имя по умолчанию строится по шаблону `%(title)s [%(id)s].%(ext)s`; расширение зависит от настроек и доступных форматов. Ошибка обложки не отменяет известное название видео.

Если хочешь изменить имя файла, наведи указатель на **«Шаблон имени файла»** для краткой подсказки или открой **«Справка…»** рядом с полем. В отдельном окне есть распространённые поля, синтаксис и примеры относительных подпапок.

Видео и аудио могут скачиваться раздельно, затем объединяться. При двух компонентах шкала всей задачи доходит до 49,5% после первого и до 99% после обоих; состояние отдельно показывает процент текущего компонента. Дождись завершения обработки и сохранения: 100% означает готовый опубликованный результат. Настоящая повторная попытка подписана отдельно; [подробности прогресса](windows-logging.md#как-читать-проценты-и-этапы).

**«Пауза / Продолжить»** приостанавливает и продолжает сессию, **«Остановить»** отменяет её с очисткой временных файлов. Кнопка **«Повторить ошибки»** повторяет неудачные задания. **«Удалить выбранные»** для начатого или завершённого задания может удалить его файлы после подтверждения — это не просто скрытие строки.

Таймер сессии включает время паузы и замирает после окончания всех заданий и очистки, в том числе при ошибках или отмене. Следующий запуск скачивания или повтор сбрасывает отсчёт. Простое добавление URL и получение превью не запускают таймер.

### Скачать фрагмент или выбрать конкретные потоки

До запуска скачивания выбери одну строку в панели «Очередь» и нажми **«Формат и фрагмент…»** под превью. Дождись метаданных. Для отрывка укажи, например, **«Начало → 00:01:15»**, **«Конец → 00:02:30»**. Для полного видео оставь оба поля пустыми.

Если источник сообщил длительность, перетащи границы на шкале под полями. Время и длительность фрагмента обновятся вместе с кадрами. Кнопки возле **«К началу»** и **«К концу»** сдвигают соответствующую границу на кадр; при неизвестной частоте кадров подпись честно меняется на шаг **0.1 с**. Перетаскивание или переход к границе задаёт явный диапазон; само открытие окна сохраняет пустые поля полного видео.

Под временем появятся **«Кадр начала»** и **«Кадр перед концом»**, если источник позволяет их получить и установлен FFmpeg. Они обновляются после паузы во вводе; **«Обновить кадры»** повторяет запрос. Конечный кадр показывает момент немного раньше границы. Если кадр недоступен, прочитай пояснение под ним: допустимый фрагмент можно применить и без картинки. Предпросмотр не запускает задание в очереди.

Кадры доступны также для завершённых HLS и статического DASH: приложение получает сегменты около нужного времени. Live и DRM для предпросмотра кадров не поддерживаются; [остальные ограничения](windows-reference.md#формат-и-фрагмент-отдельного-видео) перечислены в справочнике.

Чтобы проверить движение и звук, нажми **«Начало фрагмента»** или **«Конец фрагмента»** в блоке **«Посмотреть и послушать фрагмент»**. Программа подготовит до 15 секунд внутри выбранных границ и покажет точное время этого отрывка. Доступны **«Пауза»**, **«Продолжить»**, **«Стоп»** и полоса поиска. Для воспроизведения нужны FFmpeg/FFprobe и поддержка видео и звука в Windows. Ошибка или ожидание предпросмотра не мешают нажать **«Применить»**.

Чтобы найти паузу в речи, нажми **«Волна начала»** или **«Волна конца»**. На коротком участке вокруг границы появится измеренная громкость звука с исходными временами. Щёлкни по волне или перетащи метку: изменится только поле этой границы. Стрелки сдвигают метку на **0.1 с**, с Shift — на **1 с**. Для сохранения параметров строки нажми **«Применить»**. [Окна волны и ограничения](windows-reference.md#звуковая-волна-у-границ).

Чтобы получить несколько отдельных отрывков, включи **«Несколько фрагментов — отдельные файлы»**. Первый диапазон сохраняется в списке; **«Добавить фрагмент»** создаёт пустую строку. Выбирай строки и меняй их начало/конец теми же полями или шкалой, удаляй лишние либо меняй порядок кнопками **«Выше»** и **«Ниже»**. Допустимы до 32 непересекающихся диапазонов, в том числе соседние. Нажми **«Применить»**, затем **«Скачать всю очередь»**: URL останется одной задачей, а каждый отрывок получит свой файл. [Ограничения списка](windows-reference.md#несколько-фрагментов-одного-видео).

Если нужны определённые потоки, переключись на **«Выбрать точные форматы»** и выбери их из списка источника. Видео без звука требует отдельного аудиоформата. Оставь **«Аудиодорожка → По умолчанию»**; при несовместимости контейнера выбери подходящие потоки либо Авто/MKV. Нажми **«Применить»**, затем **«Скачать всю очередь»** в основном окне.

Скачанный фрагмент не отмечает весь URL в истории и не переводит материал подписки в обработанные. Точные ID не заменяются другим качеством, если источник больше их не предоставляет. [Все ограничения и повтор готовой строки](windows-reference.md#формат-и-фрагмент-отдельного-видео) описаны в справочнике. Эти возможности относятся к Windows; при переносе `.vdqueue` передаются только URL и названия.

### Найти ранее скачанный файл

Нажми **«История…»** рядом с заголовком **«Загрузки»**. В поле поиска можно ввести название, часть URL, источник или дату в формате `ГГГГ-ММ-ДД`. Поиск просматривает всю историю; при большом числе совпадений окно показывает последние записи и предлагает уточнить запрос.

Выбери запись и нажми **«Проверить файлы записи»**. Проверка выполняется в фоне и различает доступный файл, доказанное отсутствие и неизвестный доступ, например отключённый сетевой диск. После этого используй **«Открыть файл»** или **«Открыть папку»**. Старые записи могут не содержать путей. Отсутствие результата на диске не удаляет успех из истории и не запускает повторную загрузку.

## 2. Скачать видео из плейлиста YouTube

Если нужен один ролик из плейлиста, открой его на YouTube, скопируй ссылку без параметра `list` и следуй [первому сценарию](#youtube-video). Ниже описан импорт всего доступного набора с отдельной задачей на каждый ролик.

Для отдельных строк, статусов и повторов каждого ролика используй импорт через **«Подписки»**. Источник можно оставить для будущих ручных проверок или удалить после разового импорта.

Пример формы адреса:

```text
https://www.youtube.com/playlist?list=PLAYLIST_ID
```

1. В основном окне настрой профиль и **«Папка загрузок»**.
2. Нажми **«Подписки»**. В поле **«Канал или плейлист — любой сайт, поддерживаемый yt-dlp»** вставь URL плейлиста.
3. В **«Краткое имя / папка (необязательно)»** введи, например, `Обучение`. Если оставить поле пустым, после успешной проверки программа возьмёт название канала/автора, а при его отсутствии — название коллекции.
4. Выбери **«Добавить все материалы в текущую очередь скачивания»**. По умолчанию выбран вариант со статусом «пропущено», который сохраняет список без очереди.
5. Нажми **«Добавить и проверить»**. Первая полная проверка начнётся сразу; не нужно дополнительно нажимать **«Проверить»** во время её выполнения.
6. Дождись успешного результата. В карточке проверки видны текущий источник, этап и время; затем проверь число материалов, принятых в обычную очередь. Для ранее скачанных URL появится обычное подтверждение повтора; отмена сохраняет исходный запрос для следующей ручной проверки.
7. Вернись в основное окно и нажми **«▶ Скачать всю очередь»**. Каждый принятый ролик получит отдельное задание.

**Результат:** при указанном имени `Обучение` файлы будут сохраняться в `D:\Video\Обучение`, а с архивированием — в `D:\Video\ГГГГ-ММ-ДД\Обучение`. Ошибку конкретного видео можно повторить отдельно. Переименование подписки позже влияет на новые добавления, а имя папки уже принятых заданий сохраняется.

Удаление подписки кнопкой **«Удалить подписку»** не удаляет уже добавленную обычную очередь, скачанные файлы и историю.

<a id="если-добавить-url-плейлиста-обычной-кнопкой--add"></a>

### Если добавить URL плейлиста обычной кнопкой «+ Добавить»

Такой URL остаётся **одним заданием**, переданным yt-dlp. Он не разворачивается приложением в отдельные строки роликов: yt-dlp может скачать коллекцию, превью относится к первому материалу при наличии его метаданных, а общие название и прогресс меняются по ходу работы. История учитывает исходный URL плейлиста, не каждый URL его видео; **Открыть файл** работает с одним из итоговых файлов.

Для контроля каждого ролика и согласованного учёта в подписках используй описанный выше импорт. Прямое скачивание плейлиста не доказывает подпискам, что каждый его ролик уже был скачан отдельно.

## 3. Скачивать новые материалы по подписке

Подписка сохраняет канал или плейлист и помнит уже обнаруженные URL. По умолчанию проверки запускаются вручную. После первой успешной проверки можно включить [интервал](windows-reference.md#проверки-по-интервалу), пока приложение открыто или работает в трее. Обнаружение не начинает скачивание и не принимает материалы в очередь.

Пример формы адреса раздела обычных видео YouTube-канала:

```text
https://www.youtube.com/@CHANNEL/videos
```

Выбранный URL определяет проверяемую коллекцию. Адрес вкладки обычных видео не означает подписку одновременно на все остальные разделы канала.

### Первая проверка

1. Открой **«Подписки»**, укажи URL источника и при необходимости краткое имя, например `Канал 123`.
2. Выбери, что делать с уже существующими видео:

   | Действие с существующими материалами | Что произойдёт после первой успешной проверки |
   | --- | --- |
   | «Добавить все материалы в текущую очередь скачивания» | Все найденные URL предлагаются обычной очереди, включая ранее скачанные. Для повторов действует подтверждение истории. Уже имеющийся URL не создаёт вторую строку. Загрузка ждёт отдельного запуска. |
   | «Добавить все материалы в подписку без скачивания в статусе "пропущено"» | Значение по умолчанию: список сохраняется со статусом «Пропущено», без очереди. Нужные видео можно добавить вручную. |
   | «Добавить все материалы в подписку без скачивания в статусе "готово"» | Список сохраняется с ручной отметкой «Готово». Подсказка состояния объясняет, что файл не скачивался и успешная загрузка в историю не записана. Видео можно вручную добавить в очередь. |

3. Нажми **«Добавить и проверить»** и дождись полного успешного обхода. Неудачная первая проверка не устанавливает исходный набор; после исправления причины её можно повторить кнопкой **«Проверить»**.
4. Если выбран импорт существующих видео, запусти их **«▶ Скачать всю очередь»** в основном окне.

Уже подтверждённый реальный успех отображается как «Обработано» или «Обработано в другой подписке» и сохраняет своё происхождение при любом начальном действии. Старые подписки сохраняют прежний выбор: их записи «Исходный снимок» остаются доступны для ручного добавления. Новый выбор действует только на первую успешную полную проверку; последующие новые URL получают «Новое».

У выбранной подписки её исходный адрес доступен в поле **«URL подписки»**. Выдели его и нажми Ctrl+C либо используй **«Копировать URL»**.

### Следующие проверки

1. Когда нужно найти новинки, выбери подписку и нажми **«Проверить»**. **«Проверить все»** проверяет все неприостановленные подписки. Для принудительного обхода всего архива перед запуском включи **«Полная проверка»**.
2. Дождись завершения. Новым считается точный URL, которого программа раньше не встречала в этой подписке; дата публикации сама по себе не определяет новизну.
3. После всей проверки в окне **«Новые материалы подписок»** нажми **«Добавить в очередь»**, чтобы принять материалы со статусом **«Новое»** из успешно проверенных подписок. При **«Проверить все»** это один вопрос для всех таких источников; он включает и прежние новинки, которые ещё не были приняты. **«Не сейчас»** или закрытие вопроса оставляет их во входящих. Для выбора отдельных материалов вместо общего приёма используй **«Входящие и результаты»** и кнопку **В очередь; запуск кнопкой «Скачать всю очередь»**; несколько строк выделяются через Ctrl или Shift.
4. Перейди в основное окно и нажми **«▶ Скачать всю очередь»**. Если другая загрузка уже выполняется, материалы подписки ждут следующего запуска сессии.
5. Ненужные новые материалы можно отметить **«Пропустить»**. Пропуск не является успешной загрузкой; такой материал позже доступен для ручного добавления в очередь.

Предложение не включает источники с ошибкой и не появляется после отмены проверки. Общий вопрос касается **«Новое»**. Первичный импорт существующих видео обрабатывается отдельно по действию, выбранному при добавлении подписки.

Для повторного скачивания выбери материалы любого статуса во **«Входящие и результаты»** и нажми **В очередь; запуск кнопкой «Скачать всю очередь»**. Если выделены разные статусы, выбери **«Только новые»** или **«Всё выделенное»**; **«Отмена»** и закрытие вопроса сохраняют очередь. Когда новых нет, доступно добавление всего выделенного. Уже готовые и пропущенные строки основной очереди получают отметку повторного запуска или продолжения и ждут **«Скачать всю очередь»**. Прежние файлы, прогресс пропущенных загрузок и история сохраняются. [Подробности повторного добавления](windows-reference.md#проверка-и-действия-со-входящими).

Нажми на один материал: правая панель покажет его название, URL, состояние и подписку, затем автора, длительность и доступные форматы, если сайт их предоставил. Здесь же появятся **одно или два превью** по мере готовности. Ширину панели меняет вертикальный разделитель; URL видео можно скопировать кнопкой **«Копировать URL»** или открыть через **«Открыть URL»**. Выбор в подписках не меняет содержимое панели «Предпросмотр» основного окна; несколько выделенных материалов очищают правую панель.

После успешной ручной проверки недостающие обложки материалов подписки догружаются в фоне, ещё до добавления в очередь. Это касается и исходного снимка, обработанных и пропущенных видео. Полная проверка запрашивает материалы, подтверждённые текущим обходом; быстрая — весь сохранённый список подписки. Готовые актуальные картинки используются из кеша без повторной загрузки. Получение изображений не задерживает окончание проверки и вопрос о приёме новинок; отдельные ошибки не мешают добавить материалы в очередь.

Выбор материала в подписке также запрашивает его сведения и изображения; запрос выполняется и при добавлении в очередь. Повторное принятие уже существующей строки позволяет повторить неудавшееся получение метаданных без выбора строки в основном окне. Если название получено, но обложка завершилась ошибкой, её можно запросить заново при следующем обращении через минуту; автоматического повтора по таймеру нет. Журнал указывает видео, адрес кандидата картинки, этап и причину отказа. [Как получить диагностику](windows-logging.md).

Список **«Входящие и результаты»** сохраняет порядок источника, полученный через yt-dlp, независимо от состояния видео. При полной проверке текущие материалы идут в этом порядке, исторические записи, которых больше нет в источнике, остаются в конце. Быстрая проверка обновляет порядок проверенного окна перед прежним хвостом. **Старые подписки удалять не нужно:** один раз выполни **«Полную проверку»**, чтобы обновить порядок всего сохранённого списка.

### Как ищутся обновления

Первая проверка всегда получает полный список. При следующих ручных проверках приложение сначала запрашивает до **20 новых публикаций** у источников с известным порядком от новых к старым:

- вкладки YouTube-канала `/videos`, `/shorts` и `/streams` без дополнительных параметров URL;
- публикации Pornhub, если сборщик подтвердил раздел самых новых видео.

Если все полученные URL уже известны этой подписке, новых материалов нет. Если есть и новые, и знакомые URL, новые добавляются в список, а прежние состояния сохраняются. Учитывается сам факт знакомства с URL: «Исходный снимок», «Пропущено», «В очереди» и «Обработано» одинаково подходят для сравнения.

Если в окне нет ни одного знакомого URL, новинок могло накопиться больше 20: приложение автоматически выполняет полный обход. При неизвестном порядке или непригодном ответе также используется полный обход. Произвольные плейлисты, корневые страницы YouTube-каналов и остальные источники продолжают проверяться полностью.

Например, после **100 известных видео добавилось ещё 100 новых**. Первые 20 новых не содержат знакомого URL, поэтому приложение получает полный список из 200 материалов и обнаруживает все 100 новинок. Их можно добавить одним подтверждением после проверки и скачать через **«Скачать всю очередь»**. Окно из 20 не обрезает результат до 20 новых видео; обычные пределы полного обхода всё равно действуют.

Окно последних публикаций не сверяет старую часть архива: для перенесённых внутрь плейлиста старых роликов, смены сортировки и ручной сверки включи **«Полная проверка»** перед запуском. Пауза исключает подписку из автоматической проверки. При желании включи [проверки по интервалу](windows-reference.md#проверки-по-интервалу) после первой ручной проверки: они работают при открытом приложении и в трее, сохраняют новинки во «Входящих» и не запускают очередь. Полный выход прекращает проверки.

При **Папка загрузок = `D:\Video`** и имени `Канал 123` назначение будет `D:\Video\Канал 123`. При включении **«Архив по дате»** дата добавится перед именем подписки. Общая папка фиксируется при запуске скачивания, имя подписки — при принятии URL в очередь.

### Что означают результаты и повторы

| Состояние материала | Что делать |
| --- | --- |
| «Исходный снимок» | Видео существовало при первой проверке. Можно вручную добавить в очередь; само оно скачиваться не начнёт. |
| «Готово» в подписке | Ручная отметка при создании подписки: файл не скачивался. Подсказка состояния объясняет отличие от подтверждённой обработки. Можно добавить в очередь. |
| «Новое» | Можно добавить в очередь или пропустить. |
| «В очереди» | Материал принят, но это ещё не подтверждение успешного скачивания. Проверь основное окно. |
| «Пропущено» | Можно позже вручную добавить в очередь. |
| «Обработано» | URL уже успешно скачан; обычная проверка не ставит его на скачивание заново. |
| «Обработано в другой подписке» | Для этого точного URL уже подтверждён успех в другой подписке. После подтверждения уведомление больше не повторяется. |

Если тот же точный URL раньше был успешно скачан обычным добавлением в очередь, общая история тоже учитывается. Подписка не обязана быть источником этой прежней загрузки. Разные адреса одного видео, включая отличающиеся параметры или регистр пути, автоматически не объединяются по ID.

Исходный набор не означает «скачано»: он задаёт точку отсчёта и виден в том же списке. Это относится и к исходным материалам ранее сохранённых подписок: повторная проверка для их отображения не нужна. Для намеренного повторного скачивания уже обработанного ролика используй его обычный URL. Если строки ещё нет в основной очереди, добавь URL и нажми «Скачать всю очередь». Если строка уже есть, дождись завершения текущей сессии и выбери **Скачать повторно** в контекстном меню Загрузки либо **Скачать выбранные строки** в контекстном меню Очередь. Подтверди повтор в диалоге истории; новая копия получает свободное имя, а прежние файлы не перезаписываются.

Кнопка **«Отменить проверку»** останавливает проверку источника, а не текущие скачивания. **«Приостановить»** исключает источник из проверок; **«Возобновить»** снова разрешает ручную проверку. Удаление подписки сохраняет файлы, обычную очередь и общую историю.

## 4. Скачивать материалы через подписку с RSS / Atom

В текущей версии RSS — **не самостоятельный источник скачивания**. Нужен URL канала или плейлиста, который yt-dlp может полностью перечислить. RSS / Atom необязательно дополняет названия подтверждённых материалов; состав определяется проверкой коллекции через yt-dlp.

Для YouTube приложение может автоматически найти ленту по метаданным канала. Её можно не вводить вручную. Форма адреса ленты канала:

```text
https://www.youtube.com/feeds/videos.xml?channel_id=CHANNEL_ID
```

Здесь нужен настоящий ID канала вида `UC…`, а не `@имя`. Для другой платформы используй предоставленный ею адрес RSS / Atom, если у неё есть подходящая поддерживаемая коллекция.

1. Открой **«Подписки»**.
2. В основное поле вставь URL канала или плейлиста. В поле **«RSS / Atom (необязательно)»** вставь URL соответствующей ленты либо оставь его пустым для автоматического определения YouTube.
3. Укажи краткое имя и выбери исходный набор или импорт всех существующих материалов, как в [предыдущем сценарии](#subscriptions).
4. Нажми **«Добавить и проверить»**. Программа сначала полностью перечислит коллекцию, затем при наличии ленты прочитает её.
5. При последующих проверках нажимай **«Проверить»** или **«Проверить все»**. Прими новинки в общем вопросе после проверки либо выбери их во входящих и нажми **В очередь; запуск кнопкой «Скачать всю очередь»**, затем **«▶ Скачать всю очередь»** в основном окне.

**Результат:** загрузка и папки работают как у обычной подписки. Подключение ленты не включает расписание, автоматическое скачивание и проверку при запуске приложения.

У RSS есть четыре важных ограничения:

- Сначала выполняется проверка коллекции через yt-dlp: полный обход либо проверенное окно новых публикаций по правилам выше. Неизменившаяся RSS сама по себе не позволяет пропустить эту проверку.
- Лента дополняет отсутствующее название только при точном совпадении URL с результатом проверки коллекции. Разные варианты адреса не сопоставляются по media ID.
- Ссылка, присутствующая только в RSS, не попадёт во входящие. Поэтому в ленте канала могут быть материалы, не относящиеся к выбранному плейлисту или вкладке.
- Недоступная или некорректная лента даёт предупреждение, но успешная проверка коллекции остаётся результатом. Если она не удалась, RSS не заменит её и прежний набор не будет обновлён непроверенным списком.

Если у тебя есть только RSS без полностью перечисляемого канала/плейлиста, отдельная RSS-подписка в этой версии не поддерживается.

## Если что-то не получилось

Если при нескольких параллельных загрузках скачут проценты, выбери над журналом в **«Загрузки»** профиль **«Прогресс загрузок»** и сохрани нужный участок кнопкой **«Сохранить журнал…»**. Трасса разделяет URL, компоненты видео/аудио и повторные попытки; **«Подробный yt-dlp»** добавляет вывод процесса. [Пошаговый разбор и файлы журнала](windows-logging.md).

Для отдельной строки нажми **«Диагностика…»** в **«Очередь»** или **«Загрузки»**. Окно показывает сохранившиеся события, фактические попытки и принятые параметры выбранной ссылки, позволяет искать сообщения и сохранить [ZIP диагностики](windows-logging.md#диагностика-одного-задания). Другая выбранная строка не переключает уже открытое окно.

При русском языке интерфейса Windows приложение показывает русские объяснения ошибок загрузки, метаданных и подписок. Региональные настройки чисел и дат на выбор языка ошибок не влияют. После изменения языка Windows перезапусти приложение.

Причину ошибки загрузки можно прочитать в подсказке состояния строки или через меню **«Показать ошибку»** в панели «Загрузки». **«Исходная диагностика»** в том же меню показывает оригинальный ответ yt-dlp для обращения за помощью. В панели «Предпросмотр» оригинал доступен в подсказке сообщения, в подписках — в подсказке строки. Журнал сохраняет исходную диагностику вместе с объяснением. Если ошибка неизвестна приложению, оно сообщит об этом по-русски; автоматического перевода произвольного текста сайта нет. При другом языке интерфейса Windows исходные сообщения остаются без перевода.

| Ситуация | Что проверить |
| --- | --- |
| При запуске скачивания не найдены FFmpeg / ffprobe | Нажми **«Установить FFmpeg»** в разделе «Компоненты», дождись установки и снова нажми «Скачать всю очередь». |
| Не появляется название или обложка | Посмотри сообщение в панели «Предпросмотр» и журнал. Метаданные запрашиваются в фоне; ошибка изображения не отменяет текст и не является результатом скачивания. Для WebP/AVIF-обложек нужен FFmpeg. |
| yt-dlp сообщает об ошибке доступа YouTube | При необходимости обнови **«Обновить yt-dlp»**, проверь доступность самого материала и файл Cookies. Возможность просмотра в браузере не гарантирует такой же доступ у отдельного загрузчика. |
| После первой проверки нет новых материалов | Начальное действие сохраняет существующий набор как пропущенный, отмеченный вручную готовым либо принятый в очередь. Старые подписки могут показывать «Исходный снимок». Следующая проверка отметит новыми URL, которых ещё не было в этой подписке. |
| Подписка помнит скачанный ролик, но файла уже нет | История не очищается от удаления файла. Для новой копии используй обычный URL; существующее задание можно явно повторить через **Скачать повторно** или **Скачать выбранные строки**, когда сессия не работает. |
| Полная проверка не завершается успешно | Для обычных коллекций действуют пределы 10 000 материалов, 180 секунд и 32 МиБ метаданных. Ошибка доступа, недоступный элемент или неполный список запрещают обновление исходного набора. Проверь сообщение источника; если сайт предоставляет более узкий плейлист или раздел, можно подписаться на него. |
| RSS показывает предупреждение | Полный список и лента могут содержать разные ссылки; необязательная лента также может быть недоступна. Смотри результат полного обхода, а не только ленту. |
| Файлы попали в неожиданную подпапку | Проверь краткое имя подписки и **«Архив по дате»** после выбора профиля. Имя уже добавленного задания не меняется при переименовании подписки. |

Очередь, подписки, история и кеш находятся в `%LOCALAPPDATA%\VideoDownloader`. Открыть каталог можно кнопкой **«📁 Открыть папку настроек»**. Для переноса настроек, подписок и истории используй **«Резервная копия…»** и локальный `.vdbackup`: [состав, подтверждение и ограничения](windows-backup.md). Скачанные файлы сохраняй отдельно; не удаляй историю ради очистки обычной очереди. После запуска восстановление очереди не начинает скачивание без запуска скачивания.

Общие рецепты: [ошибки и резервное копирование](troubleshooting.md).
