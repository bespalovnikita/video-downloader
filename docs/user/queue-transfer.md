# Перенос очереди между Windows и Android

Очередь можно скопировать на другом компьютере или телефоне с Video Downloader. Windows и Android используют один формат: длинный текст, начинающийся с `VDQUEUE1:`, или файл `.vdqueue` с этим же текстом.

## Скопировать и вставить

1. На исходном устройстве открой очередь и нажми **«Перенос очереди → Копировать очередь»**.
2. Передай скопированный текст на другое устройство целиком, включая `VDQUEUE1:`. Переносы строк допустимы.
3. На другом устройстве нажми **«Перенос очереди → Вставить очередь»**. Обычная **Paste** в Windows и **«Вставить»** в Android тоже распознают этот формат.
4. Проверь появившиеся строки, выбери настройки скачивания и папку на этом устройстве, затем нажми **Start**.

Исходная очередь сохраняется. Экспорт включает все её строки, в том числе завершённые и с ошибками. На принимающем устройстве новые ссылки добавляются в конец текущей очереди в исходном порядке и получают состояние ожидания. Они ждут следующего **Start**, даже если другие задания сейчас скачиваются.

Точные совпадения URL не добавляются повторно. Существующая строка сохраняет своё состояние и положение; если у неё ещё нет названия, оно может дополниться из импорта. Ссылки с разным регистром или параметрами считаются разными. При повторе URL внутри переносимой очереди используется первая запись.

## Перенести через файл

Для большой очереди удобнее файл: общий предел копирования — **262 144 символа**. Если буфер обмена недоступен или текст не помещается, приложение предлагает сохранить очередь в файл.

| Действие | Windows | Android |
| --- | --- | --- |
| Экспорт | **«Перенос очереди → Сохранить очередь в файл…»** | **«Перенос очереди → Сохранить .vdqueue»** |
| Импорт | **«Перенос очереди → Открыть файл очереди…»** | **«Перенос очереди → Загрузить .vdqueue»** |

Сохрани файл с расширением `.vdqueue`, передай его на другое устройство и открой указанной командой. В Android файл также можно выбрать через **«Из файла»**; в Windows — через обычный импорт списка или перетащить в окно. Порядок добавления и ожидание **Start** такие же, как при вставке текста.

Ограничения одного пакета: до **100 000 записей**, **16 МиБ распакованных данных** и **24 МиБ входного текста**. Экспортируется вся очередь; отдельного выбора части строк для экспорта нет. Повреждённый пакет или неподдерживаемая версия отклоняются целиком: отдельные ссылки из него не добавляются.

Принимающий клиент также проверяет, сможет ли сохранить очередь после объединения с уже имеющимися строками. Слишком большой итоговый набор отклоняется без изменения текущей очереди, даже если сам переносимый пакет укладывается в указанные пределы.

## Что переносится

Переносятся **URL, известные названия и порядок строк**. Превью на новом устройстве получает его собственный фоновый работник; изображения в пакет не входят. Настройки качества, папка назначения, cookies, скачанные файлы, прогресс, история и связь с подписками остаются на исходном устройстве. Проверка уже скачанных ссылок при **Start** использует историю принимающего клиента.

Текст сжат и закодирован, но не зашифрован: получатель может прочитать ссылки и названия. Обычные списки URL в `.txt` и ярлыки `.url` по-прежнему импортируются обычным способом; для сохранения названий и порядка используй переносимую очередь.

Описание формата для разработчиков и общие примеры обеих платформ находятся в [контракте переносимой очереди](../../tests/fixtures/portable-queue/README.md). Другие сценарии: [Windows](windows.md) и [Android](android.md).
