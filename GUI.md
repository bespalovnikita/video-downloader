# Video Downloader GUI

Нативная Windows-оболочка для ytdl-manager-v8.ps1.

## Запуск

Самый простой вариант — двойной клик по start-gui.cmd.

Или из PowerShell:

~~~powershell
pwsh -STA -File .\ytdl-manager-gui.ps1
~~~

Нужен PowerShell 7+. Рядом должны лежать ytdl-manager-v8.ps1 и yt-dlp.exe.
Для склейки видео/аудио ffmpeg.exe и ffprobe.exe нужны так же, как в консольной версии.

## Что есть в интерфейсе

- многострочная очередь URL;
- импорт списка из txt;
- выбор папки загрузки;
- 1–32 параллельных URL;
- AutoFragments или фиксированные 1–4;
- Archive;
- SponsorBlock;
- AudioOnly;
- cookies-файл;
- таблица рабочих слотов;
- статусы Скачивается / Готово / Ошибка;
- общий прогресс очереди;
- цветной журнал;
- Stop с остановкой дерева дочерних процессов;
- кнопка открытия папки с результатами;
- Ctrl+Enter для запуска.

## Как устроено

GUI не дублирует движок. Он запускает существующий ytdl-manager-v8.ps1 отдельным процессом с выбранными параметрами и читает его лог во время работы.

Поэтому консольная версия остаётся полностью совместимой, а правила качества, fallback, fragments, cookies и SponsorBlock остаются в одном месте.

GUI показывает состояние каждого слота, название текущего видео, процент скачивания, скорость, ETA, стадию склейки и общий прогресс очереди. Для этого CLI-движок умеет писать структурированный JSONL event stream через параметр EventFile; консольный режим при этом остаётся обратно совместимым.
