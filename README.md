# Video Downloader

[![Сборка Windows](https://github.com/bespalovnikita/video-downloader/actions/workflows/native-windows.yml/badge.svg)](https://github.com/bespalovnikita/video-downloader/actions/workflows/native-windows.yml)

Приложение для скачивания видео и аудио с очередью, историей, превью и ручными подписками. Доступны два клиента: **Windows 10/11 x64** на C# / .NET 8 / WPF и **Android 8.0+** на Kotlin / Jetpack Compose. Оба используют yt-dlp; набор возможностей различается.

## Быстрый запуск

<a id="установка-windows-версии"></a>

### Windows

1. Скачай `VideoDownloader-Windows-x64.zip` из [последнего релиза](https://github.com/bespalovnikita/video-downloader/releases/latest).
2. Распакуй ZIP целиком. Сохрани соседние с EXE файлы и папки.
3. Запусти `VideoDownloader.exe`. Если FFmpeg и ffprobe ещё не установлены, нажми **Install FFmpeg** в разделе **Dependencies**.
4. Вставь ссылку на видео, нажми **Add**, выбери папку и нажми **Start**.

Установка .NET, Python и PowerShell пользователю не требуется. Windows-пакет автономный; FFmpeg устанавливается отдельно через приложение или находится в PATH. Для проверки целостности рядом с ZIP опубликован `SHA256SUMS.txt`.

После установки полного нового ZIP Windows-приложение проверяет стабильные обновления при запуске и предлагает **«Обновить и перезапустить»**. Для первого перехода с `v2.0.38` и более ранних версий скачай ZIP вручную: прежние версии ещё не умеют обновлять приложение. [Порядок обновления](docs/user/windows.md#установка-и-обновление).

### Android

Скачай `VideoDownloader-Android.apk` из [последнего релиза](https://github.com/bespalovnikita/video-downloader/releases/latest) и открой файл на телефоне. APK содержит сборку для arm64-v8a и x86_64. [Порядок установки и обновления](docs/user/android.md#установка-apk-и-обновление) учитывает переход с прежних отладочных APK; для разработки можно [собрать APK локально](docs/developer/android-build.md). После **Start** загрузкой управляет foreground service с уведомлением; переход на главный экран её не останавливает. [Ограничения Android и работа с файлами](docs/user/android.md) описаны отдельно.

<a id="подписки-на-каналы-и-плейлисты"></a>

Подписки проверяются вручную. RSS дополняет названия материалов, подтверждённых коллекцией через yt-dlp. Приём материалов в очередь и **Start** — отдельные действия. Для отдельной задачи на каждый ролик плейлист импортируется через подписку; прямой URL плейлиста в основной очереди остаётся одной задачей.

## Что умеет приложение

В Windows и Android можно выбрать оригинальную аудиодорожку или язык звука, например `ru` или `en`. Несколько выбранных языков сохраняются в одном MKV; для MP3 доступна одна дорожка. Подробнее: [Windows](docs/user/windows-reference.md#выбор-аудиодорожки) и [Android](docs/user/android.md#выбор-аудиодорожки).

В Windows для отдельного URL можно задать начало и конец фрагмента полями или интерактивной шкалой с предпросмотром двух кадров, уточнить границы покадровым шагом либо выбрать реальные форматы источника по разрешению, FPS, кодекам, языку, HDR и доступным сведениям о размере. При неизвестном FPS шаг явно задан в секундах. Можно выбрать до 32 непересекающихся фрагментов одного ролика и сохранить каждый отдельным файлом либо объединить их в один файл в порядке списка. Склейка проверяет реальные дорожки; дополнительное перекодирование несовместимых потоков требует явного выбора. Перед скачиванием можно посмотреть и послушать до 15 секунд с начала или конца выбранного диапазона; подпись показывает точный диапазон предпросмотра. Кадры требуют FFmpeg; кроме прямых потоков поддерживаются завершённые HLS и статический DASH. Live, DRM и отдельные схемы источников остаются недоступны для кадров. Ручной выбор сохраняет точные ID без подмены другим качеством; фрагмент не отмечает весь материал скачанным. [Подробности](docs/user/windows-reference.md#формат-и-фрагмент-отдельного-видео).

Звуковая волна в редакторе Windows помогает найти речь и паузы у начала и конца фрагмента. По кнопке приложение измеряет звук участка до 15 секунд; щелчок или перетаскивание метки уточняет соответствующее время. [Как пользоваться волной](docs/user/windows-reference.md#звуковая-волна-у-границ).

В Windows очередь можно искать по названию/URL и фильтровать по статусу или подписке. Видимое выделение и глобальные действия различаются явно; фильтры не меняют порядок исполнения. [Поиск и область действий](docs/user/windows-reference.md#поиск-и-фильтры).

В Windows кнопка **«История…»** открывает поиск подтверждённых загрузок по названию, URL, источнику и дате. Можно проверить сохранённые пути и явно открыть медиафайл или его папку; отсутствие файла сохраняет факт прежнего успеха. [Работа с историей](docs/user/windows-reference.md#история-и-восстановление-после-перезапуска).

Windows показывает свободное место на дисках результата и временных файлов, оценивает известные размеры выбранных потоков и предупреждает до запуска при нехватке места. Во время сессии низкий остаток показывается без остановки загрузки. [Оценка и ограничения](docs/user/windows-reference.md#свободное-место-на-диске).

Оба клиента поддерживают очередь URL, загрузку через yt-dlp, историю успешных результатов, метаданные, до 15 доступных изображений сайта, ручные подписки, cookies и перенос очереди `.vdqueue`. Обычные новые URL могут пополнять уже запущенную сессию после проверки истории; подписки и переносимые очереди ждут Start. Готовых изображений у сайта может быть меньше 15; кадры из видео для этого не извлекаются.

Оба клиента поддерживают четыре профиля журнала, общий прогресс задания, сводку сессии и сохранение диагностики. Они предлагают добавить найденные новинки подписок в общую очередь и показывают сведения выбранного материала с превью. Оба клиента используют быструю проверку подтверждённых источников с полным обходом при необходимости. Подробности и различия интерфейсов: [Windows](docs/user/windows-reference.md), [Android](docs/user/android.md), [матрица возможностей](docs/project/ANDROID_PARITY.md).
